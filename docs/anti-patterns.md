# 反例库（Anti-patterns）

> **一句话定位**：任何项目都会踩的 24 条通病——每条按「现象→根因→正解」三段组织，按首要失效面分四组（MECE）；正解一律指向哲学层对应原则（[philosophy.md](philosophy.md)，下文「哲学 §N」）与既有文档节，不另立新规则。**来源**：源项目 1.72.0 基线（commit `bba9b4e`）开发史中真实踩过并废弃的做法——A1–A20 佐证记录沿 2026-10 登记全部核验存在，A21–A23 为 2026-11-08 视觉语言收敛新收，A24 为 1.72.0 复审轮新收；逐条修复记录对照见 §五。**日期**：2026-11-12。**行数预算**：≤450 行（现 202 行）。

## 〇、分类法与快速自查清单

分类按**首要失效面**四分，组间 MECE（每条反例只入一个组，按其根因的第一落点归属）：

- **一、数值与来源治理**——值从哪来、有多少档：第二份字面量、散布实例、档位膨胀、文案双写。
- **二、布局与几何稳定性**——东西在哪、会不会动：双口径、占宽漂移、补位重排、条件性外形、透明度占位。
- **三、渲染与视觉保真**——画得对不对：假圆角壳、特效伤字、分层透明壳。
- **四、交互与动效语义**——用起来对不对：模式开关、追赶动画、属性钳制、盖写编辑、曲线错配。

设计评审与收尾验收时逐条对照，命中即按「正解」改；不改则需给出超越本库的新论证。快速自查（一行一条）：

- ☐ A1 壳圆角出现第二个 token → 删幽灵，唯一权威＋锁定镜像。
- ☐ A2 网格「公式限宽＋面板再量化」双口径 → 拉伸填充单一几何源。
- ☐ A3 滚动条占布局宽（内容随其出现/消失变窄变宽） → overlay 悬浮。
- ☐ A4 为防漂移让滚动条常驻留槽 → overlay 根治，不留槽。
- ☐ A5 负边距/宽度补偿特判抵消滚动条占位 → 禁特判，机制一次根治。
- ☐ A6 弹窗透明底＋margin 挤圆角＋手工阴影 → 不透明单壳＋系统圆角阴影。
- ☐ A7 多页内容列居中对齐、页页不等宽 → 受钳的拉伸填充等宽。
- ☐ A8 内缩量随悬停动态派生（文字抖动） → 静态值。
- ☐ A9 操作钮悬停浮在正文上争像素 → 静态排他预留＋固定操作格。
- ☐ A10 隐藏按钮后其余按钮补位重排 → 显式固定行列，隐藏留空。
- ☐ A11 特效进文字子树（正文发糊/掉帧） → 无文字图层隔离＋共享冻结单实例。
- ☐ A12 窗口外形随停靠侧/显示器布局漂移 → 删条件性机制，四角恒定。
- ☐ A13 分层透明窗口做圆角与阴影 → 系统窗框材质＋系统圆角。
- ☐ A14 纯透明度隐藏（占位残留/仍可命中） → 布局塌缩＋统一显隐管理。
- ☐ A15 代码构建的 UI 快照画刷（切主题停旧色） → 动态资源引用。
- ☐ A16 每个新场景自带新时长档 → 锚定既有档不加档。
- ☐ A17 全局「编辑模式」开关 → 常态分区手势＋多选。
- ☐ A18 拖拽跟随用动画追赶＋保存往返门住 → 直接赋值＋乐观上屏＋持久化旁路。
- ☐ A19 尺寸上下限只用布局属性声明 → 系统消息路径强制。
- ☐ A20 编辑框 z 序盖写在别处/幽灵入口叠加 → 原位结构对齐＋固定格入口。
- ☐ A21 缓动曲线实例散布多处 → 单点实例消费。
- ☐ A22 位移动画按「目标<起点」选曲线 → 按目标态语义选。
- ☐ A23 禁用灰度多档并存各自字面量 → 归一两档。
- ☐ A24 同一组固定文案两处逐字双写 → 收敛唯一来源。

## 一、数值与来源治理

**A1 壳圆角幽灵 token**｜主违：哲学 §一
- 现象：窗壳圆角出现第二个 token，与系统窗口层的裁剪值并存且可能不同值。
- 根因：壳圆角的权威是系统级裁剪，界面内第二份声明只会漂移——两值一旦分叉，壳与内容自裁剪错位。
- 正解：删幽灵 token，唯一权威一枚常量，壳层资源由锁定测试镜像它；凡权威在系统层的值，界面侧不立第二来源。（→ 哲学 §一；相关：基础篇 shape「两档判定与登记」）

**A15 代码构建的 UI 快照画刷**｜主违：哲学 §一
- 现象：界面开着切深色主题，代码构建的行不跟随、停在旧主题色（探针实证）。
- 根因：构建瞬间「查找资源」把画刷实例快照持有，主题字典整本换装后旧引用不更新——第二数值源的时间维变体（冻结在构建时刻的镜像）。
- 正解：代码构建的 UI 一律活解析引用（动态资源语义），主题活切换即跟随；双主题切换探针入锁定测试。（→ 哲学 §一；相关：基础篇 color「动态引用纪律」）

**A16 场景时长新增档位**｜主违：哲学 §三
- 现象：每个新功能引入自己的毫秒数，时长档位表持续膨胀。
- 根因：没把「时长＝档位资源」当约束，场景值被当成自由变量。
- 正解：场景常量锚定既有三档（示例值：motion.duration.fast/normal/slow），永不加档；容器级独立时长组是契约化例外，不是后门。（→ 哲学 §三；相关：动效篇「三档与场景锚定」）

**A21 缓动曲线硬编码散布**｜主违：哲学 §一＋§四
- 现象：曲线实例散布在多处动画代码里，同义曲线多份实例；锁定测试只能断言实现类型，收编即碎。
- 根因：缓动没有单点工厂，每处动画自备曲线——改一条曲线要找全仓，漏一处即不一致。
- 正解：缓动单点实例，全部动效（含窗口放置、入场、反馈层、上浮）经它消费；锁定测试断言「同一实例」而非实现类型。（→ 哲学 §一「落地判据」＋§四「单点实例」）

**A23 禁用不透明度散档**｜主违：哲学 §三
- 现象：禁用灰度多档并存（0.35/0.45/0.5 三档同现，示例值），各自字面量，无档位语义。
- 根因：逐控件随手写透明度，缺「禁用＝档位」约束；且禁用态还被错当交互守卫用（见哲学 §六）。
- 正解：归一两档——控件族与整卡灰化各一档（示例值：motion.opacity.control-disabled / card-disabled），消费者一律引用＋锁定测试互锁；禁用表达原则＝入口守卫优先、置灰为辅。（→ 哲学 §三＋§六；相关：状态篇「禁用两档」）

**A24 文案双写**｜主违：哲学 §一（同构）
- 现象：同一组固定文案（如同一个选择器的标题/占位提示/空态说明）在两个构造点逐字重复。
- 根因：文案被当成局部字符串而非设计数值——第二份字面量与幽灵 token 同构，改一处漏一处。
- 正解：收敛唯一来源类（常量/资源单点），调用方不得再写第二份字面量；跨窗复用保留单点＋注释论证。（→ 哲学 §一「落地判据 4」）

## 二、布局与几何稳定性

**A2 「公式限宽＋面板再量化」双口径**｜主违：哲学 §二
- 现象：网格列数按公式算出固定宽，再交给布局面板量化——实际恒少一列＋行内死区。
- 根因：两个几何口径失配（公式节距与面板节距差一个沟道），各算各的。
- 正解：拉伸填充单一几何源——列数与元素宽的唯一计算来源是一个纯函数，容器自排版，行满排＝视口。（→ 哲学 §二；相关：范式篇 grid「单一几何源」）

**A3 滚动条独立布局列**｜主违：哲学 §二
- 现象：内容多时滚动条出现、条目变窄；变少后消失、变宽——位置漂移。
- 根因：默认滚动容器把滚动条放独立布局列（宽 0↔N 切换），且系统滚动条样式带最小宽度下限（实测约 17 DIP，示例值）压过自定义瘦条样式。
- 正解：overlay 滚动条（定制模板＋条带最小宽高归零），悬浮内容之上、永不占布局宽。（→ 哲学 §二；相关：范式篇 scrollbar「两宿主」）

**A4 稳定留槽（常驻占位）**｜主违：哲学 §二
- 现象：为防 A3 的漂移，让滚动条永远占位。
- 根因：内容恒窄一个滚动条宽＋空闲时一条空槽，与「无滚动条时内容全宽」的用户心智相反——用错误机制（占位）去修补错误机制（占宽）。
- 正解：overlay 单一机制根治漂移，不留槽。（→ 哲学 §二；相关：范式篇 scrollbar）

**A5 宽度补偿/负边距特判**｜主违：哲学 §二
- 现象：用负边距或宽度加算逐表面抵消滚动条占位。
- 根因：补丁式特判随每个新表面复制，视口语义被破坏——修漂移的代码本身成了漂移源。
- 正解：overlay 机制一次根治；补偿类特判禁用。（→ 哲学 §二）

**A7 内容列居中对齐**｜主违：哲学 §二
- 现象：多页窗口各页内容列宽随当页最宽内容收窄，页页不等宽（实测两页相差逾百 DIP，示例值）。
- 根因：居中对齐让容器宽收缩到内容宽，而不是内容在统一宽内居中。
- 正解：拉伸填充＋最大宽上限（受钳的拉伸自动居中），多页等宽。（→ 哲学 §二；相关：范式篇 settings-ia「内容列」）

**A8 内缩量动态派生**｜主违：哲学 §二
- 现象：正文内缩随悬停状态计算，文字抖动回流。
- 根因：瞬态状态参与静态几何计算——每次状态切换都触发重排。
- 正解：内缩是静态值，任何时刻零像素争用。（→ 哲学 §二「落地判据 4」）

**A9 悬浮覆盖层替代静态内缩**｜主违：哲学 §二
- 现象：操作按钮悬停时浮在正文上方。
- 根因：按钮与正文争用同一像素——悬停即遮挡、离开即露馅，正是文字避让要消灭的争用。
- 正解：静态排他预留（内缩常驻）＋固定操作格（格子固定、隐藏留空）。（→ 哲学 §二；相关：范式篇 card「文字避让」）

**A10 等分面板/定宽换行面板做按钮区**｜主违：哲学 §二
- 现象：等分面板里隐藏一个按钮后其余按钮补位重排；换行面板的换行语义随宽度漂移。
- 根因：两者都以「可见子项」排布，不支持「隐藏留空」的固定格子语义。
- 正解：显式固定行列，每钮格子恒定。例外：等分且恒列数本身就是需求的轨行（如 chip 轨恒等分），等分面板恰是正解——判据是「需求是否就是等分」，不是面板类型。（→ 哲学 §二；相关：范式篇 card「操作格」/chip-rail「轨道」）

**A12 条件性外形（越屏裁切）**｜主违：哲学 §二
- 现象：窗口向屏外平移一个圆角半径，换取收起态右缘平直。
- 根因：条件性机制使外形随停靠侧/显示器布局漂移，内容还得配合内缩——外形不再是常量。
- 正解：删机制——可见态四角圆角恒定、窗口恒在工作区内。（→ 哲学 §二；相关：范式篇 peek-dock「唯一矩形权威」）

**A14 纯透明度隐藏**｜主违：哲学 §二（命中面关联 §六）
- 现象：按钮「隐藏」后仍占位或仍可命中，网格其余按钮位置微动。
- 根因：透明度为零既不改布局也不退场命中——视觉消失了，布局与命中都还在。
- 正解：布局塌缩＋统一显隐管理（激活立即显示、失活动画完成后塌缩、动效关闭立即切、防陈旧回调）；固定网格下塌缩子项天然留空格。（→ 哲学 §二；相关：状态篇「分层叠加」）

## 三、渲染与视觉保真

**A6 弹窗假圆角三件套**｜主违：哲学 §一（壳权威）
- 现象：弹窗透明背景＋margin 挤出圆角＋手工投影三件套；用户评价「跟整个界面不搭」。
- 根因：透明壳透出下层内容色、假圆角边缘锯齿、手工阴影与系统阴影叠加——三处都在跟系统窗口层抢「壳的权威」。
- 正解：不透明表面单壳，圆角/阴影唯一来源系统窗口层，界面侧不重复声明；材质失败时保持不透明直角回退，禁假圆角。（→ 哲学 §一；相关：范式篇 dialog「单壳与回退」）

**A11 特效进文字子树**｜主违：哲学 §五
- 现象：卡片正文发糊（亚像素文字抗锯齿失效）；长列表滚动掉帧。
- 根因：带特效的元素把整个子树渲染进中间位图并强制关闭亚像素文字渲染；逐卡片实例化特效还拖垮虚拟化。
- 正解：阴影/特效隔离到不含文字的独立层（分层状态卡片三层结构：根/阴影层/内容面），共享冻结单实例。（→ 哲学 §五；相关：基础篇 elevation「三层结构与共享冻结」）

**A13 分层透明壳**｜主违：哲学 §一（壳权威）
- 现象：用分层透明窗口实现圆角与阴影。
- 根因：分层窗口整窗离屏合成性能差，且用不了系统材质与硬件圆角——为装饰牺牲整窗渲染质量。
- 正解：系统窗框（整窗玻璃帧）＋系统材质壳＋系统圆角；材质不可用时保持不透明表面回退。（→ 哲学 §一；相关：基础篇 elevation「系统材质与回退」）

## 四、交互与动效语义

**A17 模式化交互（编辑模式开关）**｜主违：哲学 §六
- 现象：全应用唯一的「编辑模式」开关——进出状态易漏，显隐机制还吞点击（合成事件可达、实机不可达）。
- 根因：模式切换是平行的第二套交互语义，与常态手势冲突；用户被迫记忆「现在处于哪个模式」。
- 正解：常态分区手势＋多选＋右键菜单，删除模式开关。（→ 哲学 §六；相关：范式篇 card「手势分区」）

**A18 拖拽追赶动画＋保存往返门住**｜主违：哲学 §六
- 现象：拖动条目粘滞感强；松手先闪旧序帧再落新序。
- 根因：跟随用动画追赶（永远追不上指针）＋每步全量扫描＋落位被「持久化往返」门住后全量重建——显示序派生自持久化状态。
- 正解：跟随直接赋值＋命中槽缓存＋乐观上屏（同一 UI 消息内生效）＋持久化旁路化＋失败回滚。（→ 哲学 §六「用户时间主权」；相关：范式篇 tile「落位」）

**A19 交互上限由布局属性声明**｜主违：哲学 §六（真实可达）
- 现象：窗口可交互缩到极小、可拉到远超上限，最大化被钳出死区。
- 根因：布局属性的上下限只约束布局引擎，不约束系统消息路径——「合成可达、实机不可达」的镜像。
- 正解：在系统尺寸协商消息处强制一切尺寸变更；与系统交互的封送结构必须严格同构（结构尺寸错一字节＝约束从未生效）。（→ 哲学 §六「落地判据 4」；相关：适配篇 wpf）

**A20 覆盖层就地编辑/幽灵入口**｜主违：哲学 §二（结构对齐）
- 现象：编辑框盖写在错误行（旧文本在上、编辑框在下，两段并存）；幽灵入口与正文同格叠加盖写。
- 根因：编辑器不在被编辑内容的结构位置——z 序盖写代替结构对齐，坐标一漂即错位。
- 正解：编辑器落原位（同格结构对齐、不透明盖写）、入口并入固定网格；硬编码偏移对齐一律否决。（→ 哲学 §二；相关：范式篇 chip-rail「就地改名」）

**A22 位移动画按数值方向选曲线**｜主违：哲学 §四
- 现象：悬停抬升（向负值位移）被配上加速曲线——抬升加速、回落减速，与「进入态减速」的宣称相反；文档-实现不一致长期潜伏。
- 根因：「目标值<起始值＝出场」是透明度语义判据；位移可正可负，负向进入在数值上像出场——判据错配语义。
- 正解：按目标态语义选曲线——目的地是进入视觉态→减速、离开→加速；透明度场景数值判据恰与语义同向可用，位移动画禁用；语义判据写进动效规范并配锁定测试。（→ 哲学 §四「第一性依据」；实测教训与源码一致，见 §五锚点）
