# 范式·快捷操作瓦片（Action Tile）

> **一句话定位**：以「启动一个动作」为使命的小方格——图标槽＋名称带＋角标＋勾选钮四件结构，悬停上浮/按压缩放/确认脉冲/失败闪/落位五族微交互；与分层状态卡片（[card.md](card.md)）同规则不同量级，几何由自算网格（[grid.md](grid.md)）供给。**来源**：源项目 1.72.0 基线（commit `bba9b4e`）启动表面瓦片模板与动效族，经 TOKEN-MAP-V1（对账 [2026-11-fts-v1.72.0.md](../../reference/extractions/2026-11-fts-v1.72.0.md)） §3.2/§3.3 映射；实现锚点见本文「fts 溯源与可移植要点」。**日期**：2026-11-12。**行数预算**：≤350 行。

## 一、问题与适用

**要解决的问题**：

1. **动作入口需要比卡片更重的反馈量级**：瓦片是一次点击即触发的动作（启动应用/打开链接），微交互（位移/缩放/脉冲）必须与「内容展示型」卡片的克制度拉开差距，又不破坏同一语言。
2. **图标在途与失败的表达**：图标提取/网络抓取异步回填、启动可能失败——瓦片要在同一几何里表达「占位→就位」「成功→失败」而不改变布局。
3. **点击语义分区**：启动、聚焦、改名、多选四种意图共存于一个小表面。

**适用**：等尺寸动作入口的水平/网格排布；图标为主、名称为辅；单机桌面或 Web 启动面板、工具盘。**不适用**：内容预览（用分层状态卡片）；不等宽异构条目（用列表）。

## 二、结构分解

1. **瓦片根**：一个圆角表面（表面档圆角）承载底色与 2px 透明描边——描边常在但透明，是失败态（危险色描边）与选中/拖放态的预留给养，切换只换描边色不加宽。根上挂渲染变换组（平移＋缩放，中心即元素中心），全部微交互只动这组变换。内边距上下 8、左右 6，是图标与名称的排版内衬。
2. **两行内容**：
   - **图标槽**（48×48 命中格、居中、下距 6）：内部按条目类型分支两态模板——应用类「占位字形＋图片提取链」（图片未到达显字形、回填即整层收起，透明图片不透出字形轮廓）；链接类「地球字形（抓取中/失败可见）＋图片」两态。图标槽同时是**启动手势分区**：单击＝启动（多选非空时挂起改选中）、拖拽仅从此区发起。
   - **名称带**（底部整带命中，圆角＝控件档）：单击＝不启动仅聚焦、双击＝就地改名（系统双击时限）、多选非空时单击改选中；悬停轻微底色提示可双击（属性瞬切轨道，[《交互状态》](../interaction-states.md)「hover 双轨」）。带内两行名称（限高 32、行尾省略、悬停全文提示）；改名期名称文本与行内编辑器同格互换（同度量：同字号/行高/限高，高度恒定）。
3. **两枚叠加小件**（不占内容流）：**警告角标**（失败灰态可见；16×16 胶囊圆角＝高一半的派生值，危险色底＋反白「!」）；**右上勾选钮**（多选入口；30×30 命中、16×16 环——悬停换强调色环、选中实心填充＋对勾，环圆角取登记值 5px（示例值：`dimension.radius.selection-ring`）；可见性＝悬停∨选中∨键盘聚焦三信号或）。
4. **右键菜单**：查看态四项起（打开/重命名/编辑目标/上移/下移/删除，删除独立分组用危险色）；菜单行圆角取置顶钮登记值、悬停换底；**按态禁用**——不可用项在打开瞬间按当前下标置灰（控件禁用档 0.4，示例值：`motion.opacity.control-disabled`），不预先隐藏。

## 三、状态与动效

微交互五族（全部只动渲染变换或不透明度，减动效时直达终态——[《动效》](../motion.md)「减动效」）：

| 族 | 触发 | 编排 | 数值（示例值） |
|---|---|---|---|
| 悬停上浮 | 指针进入/离开 | 平移 −2px；抬升减速、回落加速（按语义选缓动，《动效》「缓动」） | `dimension.offset.tile-hover-lift` −2px；`motion.duration.hover-feedback` 167ms |
| 按压缩放 | 左键按下/抬起 | 缩放至 0.96，两轴同帧 | `motion.scale.tile-press` 0.96；`motion.duration.press-feedback` 83ms |
| 确认脉冲 | 启动成功 | 缩放 1→1.06→1（峰在中点）＋不透明度 0.8→1 闪；减动效＝闪即时 | `motion.scale.launch-confirm-pulse` 1.06；`motion.duration.launch-confirm` 250ms |
| 失败闪 | 启动失败 | 不透明度 1↔0.2 两闪后，常显危险色 2px 描边＋图标半透明＋警告角标接管（常显信息不依赖动画承载） | 步进 83ms（`motion.duration.press-feedback`） |
| 落位 | 真正新增项 | 缩放 0.8→1＋不透明度 0→1，多选批量按 40ms 交错 | `motion.duration.item-landing` 250ms；`motion.duration.stagger-step` 40ms |

另有**重复项脉冲**（添加已存在项：既有瓦片闪 0.8→1 并滚动进入视野——引导到既有实体，不新增）；**表面展开交错入场**（收起→展开时全部瓦片交错入场，步进封顶 min(i,8)×40ms，收起重置标记再展开重播——《动效》「编排」交错规则；封顶 token 为文档性登记）。状态层语义（选中底色、悬停底色）引用《交互状态》「分层叠加」与「pressed 三范式」（瓦片族＝缩放轨道）。

**守卫**：启动有重入门闩（同一时间窗内第二击不重复派发，500ms 行为计时器非视觉档）；拖拽仅从图标槽发起；落位动画只在「真正新增」触发——排序/图标回填/改名/撤销恢复一律不触发。

瓦片宽是**下限而非定值**——实际宽由网格拉伸填充摊分（[grid.md](grid.md)）。**视口内衬是几何与动效的耦合点**：悬停上浮 −2 与确认脉冲 1.06（上下各溢出约 3）都是渲染变换，溢出越过滚动视口缘即被裁剪——首/末行没有行间沟道缓冲，顶/底内衬恰在列表自然停位提供余量，护住首/末行圆角；内衬随内容滚动，不占布局列。

## 五、已知反例

1. **用布局属性做微交互**（margin/top 位移、宽高缩放）：每帧重排、相邻瓦片被推挤——只动渲染变换。
2. **动效溢出被视口裁剪**：首行瓦片悬停上浮时顶圆角被切——要么内衬吸收，要么扩大裁剪区；两者选一，禁止「恰好不溢出」的侥幸取值。
3. **失败态只靠闪烁表达**：动画结束后状态消失——闪烁是**转向**常显态的过渡，常显信息（描边/角标/半透明图标）必须独立在场（《动效》「原则」：动效永不作信息唯一载体）。
4. **确认脉冲后不复位**：峰值即终态会让瓦片永久放大——关键帧必须回到 1。
5. **落位动画对一切插入播放**：排序/图标回填/改名都插容器，全员动画等于噪音——只在「真正新增」触发。
6. **名称带高度随行数变化**：一行名/两行名瓦片高不一致，网格行高漂移——限高两行＋省略号＋悬停全文。
7. **改名编辑器独立度量**：与显示态字体/行高不一致，互换时跳动——两态同度量同格互换。
8. **右键菜单预先删项**：上下文随下标变化，预先构造会错位——打开瞬间按态设定、不可用置灰不隐藏（《交互状态》「禁用档」表达原则）。
9. **勾选钮常显**：非多选语境常显角标钮污染瓦片——三信号或（悬停∨选中∨键盘聚焦）才可见。

**可移植要点**：

- **纯结构可直接抄**：四件结构（根/图标槽/名称带/叠加小件）、分区语义、右键菜单按态禁用——任何栈零翻译。
- **微交互 CSS 直译**：`transform: translateY(-2px) scale(.96)`＋`transition`；确认脉冲用 `@keyframes`（50% 峰值 1.06）；失败闪同理两闪后切换到常显类名。悬停/按压时长分别对应 hover/press 反馈档。
- **图标两态模板**：等价于 `<img>` 出错/在途时显示占位字形——用 `loading`/`error` 状态类切换，图标回填即隐藏占位层。
- **视口内衬**：滚动容器 `padding-block`（随内容滚动）而非视口装饰——直接照搬；同理护住首/末行圆角的裁剪问题在 Web 滚动容器同样存在。
- **WPF 特有需翻译**：渲染变换组须预声明再按需动画（变换对象替换）；系统双击窗判定（改名进入）在 Web 用原生 `dblclick`；勾选钮的三信号或可见性用 `:hover`＋属性选择器组合。
