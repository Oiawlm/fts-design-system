# 范式·chip 过滤轨（Chip Filter Rail）

> **一句话定位**：横条内多选一过滤与轻量归属的完整配方——「全量伪 chip＋固定槽 chip」五件套分层结构、悬停/点击双轨过滤、落点指示环三态语法、拖放撤离保持窗与共享改名会话；适用于内容列表上方 2–6 槽的窄横轨。**来源**：源项目 1.72.0 基线（commit `bba9b4e`）子分组过滤轨实证，经 PLAN-V1（对账 [2026-11-fts-v1.72.0.md](../../reference/extractions/2026-11-fts-v1.72.0.md)） §2.2 分片。**日期**：2026-11-12。**行数预算**：≤400 行（现 97 行）。

## 一、问题与适用

1. **问题**：一条高约 36 逻辑像素（示例值：结构性尺寸，非 token）的窄横轨，要同时承载四类操作——**多选一过滤**（快速缩小列表）、**指定收集落点**（新收集内容自动归属到某槽）、**就地改名**（双击改名不打断流）、**拖放归属**（把卡片拖到槽上批量归类）。空间只够放文字 chip，四类语义必须靠「手势×修饰键×状态标记」编码，而不是加按钮。
2. **适用判据**：①槽位数固定且少（约 2–6，本范式实证为 4 槽＋1 全量）；②每槽标签短（本实证限 3 字符，示例值：目录常量非 token）；③过滤是**暂态**（离开即恢复），落点是**持久意图**（会话内记住）——两者必须用不同视觉语言区分；④轨横在内容与操作之间、悬停即过滤有误触风险时，应可切换为点击轨（见 §三.2）。
3. **不适用**：槽位需动态增删或滚动（改用可滚动 chip 列表，等分不再成立）；需要多选组合过滤（用复选框组或分面过滤器）；需要复杂层级（用树/级联）。

## 二、结构分解

1. **轨道宿主＝等分容器**：轨是一个边框容器（透明底、固定高），内部条目控件＋**均匀网格恒等分**（列数＝槽数＋全量）。等分纯靠布局面板原生能力，无自定义几何——窄空间里 chip 宽度不谈判、不出现「最后一个特别宽」。轨整体显隐由**单一布尔**驱动（模式开关开启 ∧ 当前分类具备槽语义），不给每 chip 单独显隐条件。
2. **chip＝容器＋四层叠加＋两内容件**（自下而上）：

   | 层 | 职责 | 语法 |
   |---|---|---|
   | 容器 | 命中与描边 | 透明底＋1px 默认描边；悬停换悬停描边；小圆角 6（示例值：小件派生登记字面量，非 token，规则见形状基础篇）；承载全部手势事件 |
   | 悬停层 | hover 反馈 | 悬停表面色、透明度 0 起、**不参与命中** |
   | 激活层 | 过滤选中态 | 活动层底色＋强调色描边，由「本 chip 过滤激活」布尔驱动 |
   | 拖放层 | 拖放落点态 | 落点层底色＋强调色描边，由「本 chip 是当前拖放目标」布尔驱动 |
   | 落点指示环 | 收集落点标记 | 右上角标小圆环，三态语法见 §三.4；不参与命中 |
   | 文字｜编辑器 | 内容互斥件 | 显示名（次级文字色；激活时换主文字色＋半粗）与就地改名编辑器二选一显示 |

3. **全量伪 chip（all-items chip）**：轨首恒有一个「全部」chip——**无槽位、无环、无编辑器、无拖放事件**，只挂悬停与单击释放两个事件；语义＝回到全量态（过滤清空、全体 chip 激活）。它**复用同一套样式族**：靠数据侧与槽 chip 同名的属性（激活布尔、显示名）命中同一组样式触发器（样式级鸭子类型），而非复制第二套样式。
4. **模板分派＝名义类型二分**：模板选择器按条目的**实际类型**二分（全量型→全量模板、槽型→槽模板）。禁止给槽 chip 添「伪槽」字段冒充全量、或在两类型间散布类型守卫——类型分派只发生在选择器一处。
5. **样式族跨宿主复用**：落点指示环（以及激活层语言）同时被导航轨标签宿主复用——两宿主数据侧属性同名（环态枚举同名），同一枚样式单点回归。规则只立一次，环显隐不写第二份。

## 三、状态机与手势

1. **默认轨＝悬停过滤（零防抖）**：指针进入 chip → 守卫链 → 单点设置过滤。守卫链五条件任一成立即忽略进入：窗口关闭中／改名会话激活／**拖拽在途**（拖卡滑过 chip 也会触发进入事件，是假信号，必须挡）／外部拖放轨可见／搜索激活（搜索压倒过滤：不进入、不退搜索、不动过滤）。同槽幂等早退。退出＝Esc／切分类／模式切换／悬停其他 chip（含全量）。**不做防抖**：过滤是轻量纯视觉操作，防抖反而制造迟滞。
2. **点击轨＝手势重路由（A/B 双轨共存）**：实验开关切换到点击轨时，**过滤状态机与消费点零改动**，只改「事件→动作」映射——指针进入事件对开态直接返回（悬停退役为纯视觉：hover 层由模板的指针悬停态驱动，样式零变化）；裸单击＝切换过滤（再点取消；搜索态冻结无操作）；单击全量＝进全量态／再点回根；模式开关切换时清过滤＋清提示，零残留。悬停误触的根治手段不是防抖而是**换手势承载**。
3. **Ctrl+单击＝设收集落点（双轨共用）**：把「当前分类的默认槽」设为该槽，此后剪贴板捕获与外部拖入按此落卡。性质：**会话态、不持久化、无取消手势**（单击即换）、每个内容分类独立。角色闸：只有承载收集语义的分类（内容分类）才有落点概念，核心侧入口另设纵深守卫。
4. **落点指示环（destination ring）三态语法**：**紫（强调色）＝当前有效落点**；**灰（复用次级文字色，非新色）＝具备能力但当前不是有效落点**（含未设默认时的兜底位＝显示序首槽，恒灰）；**无环＝永不具备落点能力**。轨可见时**恰一枚环**。紫严格保留给有效落点——未设默认时若给兜底首槽画紫环，是假信号；灰环对无能力宿主是噪音（会被误读为「有能力未启用」），故无能力宿主恒无环。环是**状态语言**（透明度/描边色切换），无动画。
5. **驻留提示**：悬停计数与手势提示**不自研计时器**——用平台提示件的首显延迟承载（300ms，示例值：行为计时器豁免，非视觉档 token）；内容两行＝「名称·卡片数」＋当前轨模式的手势提示句。计数与文案由**单一喂数点**刷新（读源集合、非界面线程封送到界面线程）。
6. **拖放＝撤离保持窗＋插入指示**：
   - **chip 侧**：拖卡悬停 chip＝该 chip 差分高亮（拖放层），松手＝批量归属该槽（过滤激活时禁）；全量 chip 不参与（修饰键不发明交互——全量无落点语义，Ctrl+悬停＝无操作）。
   - **撤离保持窗（120ms，示例值：motion.duration.drop-target-hold）**：指示从「断言（命中）」到「撤离（离开）」不立即清——**版本号＋断言时刻＋帧循环重验**：撤离时版本自增；若从未断言过则立即清（不留「可见但透明」悬置态）；否则逐帧检查断言时刻距今未满窗则续排一帧，窗内任何**重断言使旧复核作废**（指示持续可见、激活态不翻转），消灭「隐-现脉冲」。该窗覆盖手抖往复（约 ≥4Hz 抖动全吸收）。保持窗机制在「插入指示线」与「分类/轨高亮」两处同构实现。
   - **插入指示线（列表侧，同属拖放反馈族）**：2px 高强调色圆角横线，覆盖层放置、**不参与命中**；落点槽位在条目**竖直中线**处翻转（间隙整体归其后槽）、相邻槽位翻转迟滞 ±3 逻辑像素（示例值：几何常量，防光标微动致槽位抖动，跨多槽跳变不迟滞）、边缘钳制；同位（无变化）整区隐藏。
7. **共享改名会话（就地改名）**：双击进入（判定在按下事件的连击计数；单击类动作在释放事件；两处都要排除「点在编辑器内」）。会话状态机：

   ```
   idle ──双击进入（草稿=显示名；低优先级延迟聚焦＋全选，等模板触发器先落定）──▶ editing
   editing ├─ Enter（非输入法组合期）→ 提交（结束会话→表面重估→有变化才保存）
            ├─ Esc（非组合期）→ 取消（丢弃草稿、清理组合标记）
            ├─ 失焦 → 提交（同一路径；组合标记一并清理）
            ├─ 会话外按下 → 提交（窗口级预览隧道统一冲刷）
            ├─ 面板切换 → 提交冲刷（按登记序：分类名→chip 名，先于视图突变）
            ├─ 输入法组合 start/update → 编辑器入组合集：Enter/Esc/限长全部旁路
            └─ 组合终结/失焦 → 出组合集（标记滞留＝下次 Enter/Esc 永久失效）
   非组合期文本变化 → 限长归一（超限截断）＋光标置尾
   ```

   **共享的理由**：多个改名位（分类名、chip 名）的会话机器逐字镜像，收敛为**单一会话类**、被改对象经构造参数注入；新增一个改名位＝登记一个实例。事件入口全部走**窗口级挂接**（编辑器在数据模板内，不经标记散挂、按事件源过滤编辑器）；「点外提交/切走冲刷」遍历同一登记清单。宿主窗口级的 Esc 语义（关窗/退搜索）另有独立的输入法组合守卫条目，见适配指南 WPF 篇陷阱集——就地编辑的组合守卫随会话机器存续，不并入宿主守卫。

## 四、动效编排

| 反馈 | 动效 | token 路径（示例值） |
|---|---|---|
| chip 悬停层淡入 | 透明度 0→1 | motion.duration.hover-feedback（167ms） |
| 激活层/拖放层淡入 | 透明度 0→1 | motion.duration.fade-visibility（120ms） |
| 插入指示线淡入 | 透明度 0→1 | motion.duration.press-feedback（83ms） |
| 拖放撤离保持窗 | 保持窗时长 | motion.duration.drop-target-hold（120ms） |
| 环/文字/描边状态切换 | 无动画（状态语言） | — |

编排原则：①反馈全部走**独立叠加层**，不改变布局尺寸（不引起重排）；②**差分应用**——状态翻转时才动指示，保持窗内重断言零回落（见 §三.6）；③状态语义（环、选中、禁用）一律瞬切，动效只用于「过程反馈」（悬停、淡入），两层不混用（对齐交互状态篇的类型学分层）。

## 五、已知反例

1. **悬停误触**：轨横在卡片与头部操作之间，悬停即过滤必然误触——根治是换手势承载（点击轨 A/B），不是加防抖；两种模式经偏好开关共存、切换零残留。
2. **环被误读为选中态**：紫环＝落点、灰环＝兜底/具备能力、无环＝无能力——若紫环出现在非有效落点上即假信号；灰环出现在无能力宿主上即噪音。环与选中态（激活层）是两套语言，禁止互相借用。
3. **输入法组合期 Enter/Esc 被当提交/取消**：组合期按键属输入法操作（确认候选），必须旁路；组合标记滞留会让同一编辑器下次 Enter/Esc **永久失效**（双处镜像点名）。
4. **组合期限长截断候选**：组合期不做限长，组合终结后统一收敛归一。
5. **拖拽在途的进入假信号**：拖卡滑过 chip 会触发指针进入事件，必须经守卫链挡掉，否则拖放中途过滤被改写。
6. **撤离立即清导致隐-现脉冲**：指示在断言/撤离间快速闪烁；保持窗＋版本化重验消灭之；但**从未断言过**的撤离必须立即清，否则留下「可见但透明」悬置态。
7. **修饰键发明交互**：「全量」没有落点语义，Ctrl+单击全量＝无操作——不为对齐手势网格而发明无意义动作。
8. **小件圆角并入语义不相属的 token**：chip 圆角 6 与别的 6 值控件（如置顶钮）语义族不同，**不引用对方 token**，按小件派生规则登记字面量（形状基础篇登记制）。
9. **双击判定与单击动作的事件错位**：双击判定在按下（连击计数≥2）、单击动作在释放；两处都必须排除编辑器内点击，否则改名中一次点击被当过滤。
10. **后台喂数跨线程**：集合变化可能在非界面线程到达，计数/文案喂数点统一封送，不各处自行调度。
