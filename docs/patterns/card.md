# 范式·分层状态卡片（Layered Card）

> **一句话定位**：内容卡片的可整体移植方案——三层外壳隔离阴影与文字、五个独立状态层交叉淡入承载全部交互态、右上操作格固定预留零漂移、对分手势分区消解卡面手势歧义；本体系最具代表性的表面范式。**来源**：源项目 1.72.0 基线（commit `bba9b4e`）主列表卡片模板与样式族，经 TOKEN-MAP-V1（对账 [2026-11-fts-v1.72.0.md](../../reference/extractions/2026-11-fts-v1.72.0.md)） §3.2/§3.3 映射；实现锚点见本文「fts 溯源与可移植要点」。**日期**：2026-11-12。**行数预算**：≤350 行。交叉引用：[tile.md](tile.md) 的抬升对仗、[scrollbar.md](scrollbar.md) 的几何解耦。

## 一、问题与适用

**要解决的问题**：

1. **状态与排版互相牵连**：选中/悬停若用「换底色/换描边」实现，要么整卡重绘闪烁，要么状态切换牵动布局；密集列表里逐卡重排是滚动卡顿的主源。
2. **阴影伤害文字**：把投影直接挂在内容元素上，渲染管线会把整棵子树压进中间位图并关闭子像素文本渲染——小字号正文发糊是这类实现的必然后果，且常被误诊为字体问题。
3. **悬停才出现的操作钮挤压内容**：操作按钮悬停淡入时，若正文不预留排他空间，文字与按钮争用同一批像素；若按悬停动态内缩，正文又会在悬停瞬间回流。
4. **一张卡多种点击语义**：双击编辑、单击选择、拖拽、复制并存于同一表面，若无分区判定，手势互相误触。

**适用**：垂直滚动的密集内容列表；每条内容需要 2–4 个轻量操作（选择/删除/置顶/备注类）；需要就地编辑与拖拽。**不适用**：横向流布局（用瓦片网格，见 [tile.md](tile.md)）；单屏少量展品（直接摆表面，不需要列表宿主机制）。

## 二、结构分解

1. **三层外壳（自外向内）**：
   - **根容器**：只承载外距与悬停上浮（渲染位移），不携带任何位图效果——它是最外层的「账本层」；
   - **阴影层**：与卡片同形状的不透明底专门承载投影，不承载内容、不参与命中测试——把投影绘制在文字子树之外，是文字清晰的隔离手段；
   - **内容面**：不透明卡片底色＋1px 描边＋圆角，同样禁止携带效果。三层职责互斥：位图效果永远只进阴影层，文字永远只进内容面（原则见[《层级与材质》](../foundations/elevation-and-material.md)「三层结构」「共享冻结」）。
2. **五个独立状态层（内容面之上的叠加层）**：悬停填充层、悬停描边层、选中填充层、选中描边层、编辑环层——每层一个语义、各自透明度归零为基态、全部不参与命中。状态视觉＝层透明度交叉淡入，不换底色、不重排（见[《交互状态》](../interaction-states.md)「分层叠加」）。填充层圆角取「外层−描边」派生值，描边层外扩 1px 对齐描边中心（派生规则见[《形状与间距》](../foundations/shape-and-spacing.md)「派生三族规则」）。
3. **内容网格（两行）**：行 0＝备注行（有备注或备注编辑期占行，空则塌缩）；行 1＝内容视觉层，按内容类型二选一——图片态全宽缩略图（高固定、等比裁剪）或文字态正文（限高＝行高×行数上限，行尾省略）。文字态是唯一施加避让内缩的层（见 §四）。
4. **对分手势分区命中层**：内容视觉层之上叠加一个两列等分的透明命中网格，区域＝元素身份（左半＝内容区，右半＝操作区）——星号布局随实际宽度自动对半，与 DPI 无关、无几何常量可漂移。指针命中总落在命中层上，判定沿可视树读区域标记，与视觉布局解耦。左半承载双击编辑与拖拽起点、无左键选择语义；右半承载左键复制；右键选择手势全卡面统一不分区域。卡片边缘环带不经过命中层、按默认归左半（贴边点击承载拖拽）。
5. **右上操作格（固定预留）**：绝对两列×按钮行的网格，格子与按钮行同宽同高（正方形格）；按钮行之间以独立间隔行承载间隙。行优先序：选择｜删除｜置顶｜备注，此后新增按钮按行优先向下占格，再以追加行扩展（AI 整理｜插件动作两格）。**格子固定**：按钮按可见性矩阵隐藏时格子留空、其余按钮零漂移。操作钮是命中层的子元素，按钮命中走按钮分支（独立意图会话，不参与双击窗、滑离释放取消）。
6. **列表宿主与分区边界**：列表项容器模板分两行——行 0＝分区边界宿主（两根同格互斥的分隔线＋可选组头标题，不参与命中、基态塌缩），行 1＝卡片本体。**固定置顶（pin）分区边界四态**（无／实线／虚线／强调条）由槽位样式资源承载、按用户偏好换装，「无」态零高＋空描边＝零渲染；**分组边界**是恒可见的独立线（同几何同色值、不经偏好槽位）；组头标题只在命名组边界卡非空时占行。边界由数据字段驱动触发器显隐，在容器回收复用下随数据重评——禁止代码后置逐容器设状态、哨兵数据项与第二套边界判定。
7. **就地编辑器**：与显示态正文同度量（同字体/行高/限高），编辑期盖写同一区域、显示态保持可见不塌缩，卡片高度恒定。

## 三、状态与动效

| 状态 | 视觉 | 动效 |
|---|---|---|
| 悬停 | 填充层＋描边层交叉淡入；根容器上浮 −1px（示例值：`dimension.offset.card-hover-lift`） | 167ms（示例值：`motion.duration.hover-feedback`）；抬升减速曲线、回落加速曲线——按语义选缓动不按位移方向（[《动效》](../motion.md)「缓动」） |
| 选中 | 选中填充层＋选中描边层淡入；选中态是底色叠加，不是换肤 | 120ms（示例值：`motion.duration.fade-visibility`） |
| 悬停∧选中 | 两组层叠加共存，无互斥 | 各自独立淡入 |
| 就地编辑 | 编辑环（强调色细环）声明于选中环之后，两者叠加时编辑环在上；焦点迁移不终结编辑会话 | 120ms（示例值：`motion.duration.fade-visibility`） |
| 操作钮显隐 | 悬停∨选中即淡入（可见性矩阵：如删除钮对已选中卡隐藏、备注钮按内容状态门槛） | 层淡入，与状态层同机制（《交互状态》「hover 双轨」层淡入轨道） |
| 禁用（整卡） | 整卡灰化一档 0.6（示例值：`motion.opacity.card-disabled`） | 无动画，直接生效（《交互状态》「禁用档」） |
| 减弱动效 | 全部交叉淡入与上浮直达终态；状态语义不依赖动画承载 | 《动效》「减动效」统一退化 |

上浮是**渲染位移**：不参与布局、不影响命中测试（《形状与间距》「位移与间距分立」）。阴影共享冻结的单实例（虚拟化列表性能前提）。

要点：**排他内缩是静态派生公式**（列数×列宽＋间隙），唯一来源是派生资源，不得在别处写死第二个数值；只作用于文字态、图片态与命中层全幅不变；静态值不随悬停变化——按钮显隐不牵动正文回流。边缘环带宽度＝内容内边距（12px），是手势分区的默认归左边界。分区边界线的左右对齐卡片外距（12px），上下构成「4＋8／2＋10」呼吸节奏。

## 五、已知反例

1. **把投影挂到内容面或根容器**：整棵子树进中间位图、子像素渲染关闭、正文发糊——阴影必须隔离在专用层（§二.1）。
2. **逐卡实例化阴影**：虚拟化列表滚动时每容器建效果对象，帧率坍塌——共享冻结单实例。
3. **按悬停动态内缩正文**：悬停瞬间全文回流换行，视觉抖动且命中漂移——静态排他内缩是被明确否决后确立的方案。
4. **操作钮用流式布局（等分网格/换行面板）**：隐藏按钮不保证留空，其余按钮漂移——绝对行列＋间隔行才有「隐藏即留空」。
5. **以 margin 承载按钮行间隙**：正方格＋边距过约束，间隙不可靠——独立间隔行。
6. **代码后置逐容器设分区边界**：容器回收复用下状态与数据脱钩，出现幽灵边界——边界判定只属于数据触发器。
7. **换底色式选中态**：与主题替换、悬停态互相覆盖，且无法与悬停叠加——状态层叠加是唯一正解（《交互状态》「分层叠加」）。
8. **把提示挂到命中层之下的元素**：叠加命中层后其下元素永不收到指针——挂到命中层祖先。
9. **列表几何随滚动条出现漂移**：默认模板滚动条占独立布局列，卡片宽度跳变——滚动条必须 overlay（[scrollbar.md](scrollbar.md)「不占布局宽」）。

**可移植要点**：

- **三层外壳在 CSS 是降维实现**：浏览器投影不触发中间位图问题，`box-shadow` 直接挂卡片元素即可；但「状态层叠加」仍应保留——伪元素/绝对定位子层＋`transition` 交叉淡入，等价于五状态层，收益是状态可叠加、可中断、不重排。
- **悬停上浮**：`transform: translateY(-1px)`＋transition 即渲染位移的直译；切勿用 `top`/`margin`。
- **手势分区**：两个绝对定位半区元素＋各自指针事件即可；「区域＝元素身份」（标记挂在元素上、判定沿树上行）比坐标几何判定抗 DPI 与重构。
- **操作格**：CSS Grid `grid-template-columns: repeat(2, 30px)`＋隐藏按钮 `visibility: hidden` 即「留空不漂移」；排他内缩＝正文元素 `padding-right`，由公式推导值注入。
- **分区边界四态**：等价于一个按偏好切换的类名/样式槽；「无＝零高＋不渲染」与「数据字段驱动」两条纪律直接照搬。
- **WPF 特有需翻译**：容器回收复用（虚拟化）下的触发器重评、共享冻结效果实例（`po:Freeze`）、附加属性承载的淡入动画——Web 无对应物，按各框架的状态合成机制重述即可。
