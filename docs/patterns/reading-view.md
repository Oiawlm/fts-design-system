# 范式·Markdown 阅读视图（Reading View）

> **一句话定位**：归档内容的安全阅读面——只读双态切换（编辑器仍是唯一事实源）、标题三档＋正文的阅读字号档、颜色零新增（全走主题语义键活引用）、代码字体独立、语法子集降级与链接白名单；适用于「写一次、多次读」的内容型表面。**来源**：源项目 1.72.0 基线（commit `bba9b4e`）记录归档视图实证，经 PLAN-V1（对账 [2026-11-fts-v1.72.0.md](../../reference/extractions/2026-11-fts-v1.72.0.md)） §2.2 分片。**日期**：2026-11-12。**行数预算**：≤400 行（现 65 行）。

## 一、问题与适用

1. **问题**：归档内容以轻量标记（Markdown）书写，但日常消费是**读**。让用户直接看源文＝认知税；引入富文本编辑器＝双向同步地狱＋注入面。需要的是：源文仍是唯一事实源，阅读态只是**另一个只读呈现面**——渲染纯函数、颜色零新增、不安全的语法天然降级。
2. **适用判据**：①内容「写一次、多次读」（日志/归档/复盘）；②作者与读者是同一人（不需要协作渲染差异）；③内容含轻量结构（标题/列表/代码/引用/链接）。不适用：富文档协作（用专门编辑器）；表格/脚注重的内容（本范式刻意不解析超集，见 §三.4）；实时预览分屏（本范式是整面切换，不是并排）。
3. **三条底线**：**只读**（防误改归档）、**离线**（不加载任何远程资源）、**零新增颜色**（阅读面复用主题语义键，主题切换即时生效）。

## 二、结构分解

1. **切换钮＝分段控件**：视图左缘「阅读｜编辑」两段，单选语义组（原生互斥），选中态＝活动层底色＋半粗（复用导航轨选中语言，不引入新状态色）；默认编辑态；整条默认隐藏（随实验开关出现，见 `experiment-toggle.md`——阅读视图本身是实验开关的门控对象，开关关闭时逐像素等于现状、零占位）。
2. **两视图互斥叠放**：编辑器与阅读视图同占一个布局槽，靠显隐互斥（不重挂载）；阅读视图是只读流文档渲染器（滚动、选中、复制可用；无编辑）。
3. **渲染管线两段式**：**解析映射器**（源文→纯文档模型，零界面依赖）＋**渲染器**（文档模型→流文档呈现）。可点击性等界面语义由渲染侧判定，映射器不掺界面语义——两段都可独立单测。
4. **排版件清单**：正文/标题/段落/代码块/行内代码/引用块/有序无序列表/分隔线/链接。刻意**不解析**：表格/脚注等超集语法（按普通文本安全降级）、图片与原始 HTML（离线＋注入面收窄）。

## 三、状态机与手势

1. **双态切换**（态＝会话内布尔，不持久化——重启回编辑态，不为实验性功能扩大持久化面）：

   ```
   编辑态 ──单击「阅读」──▶ 阅读态（从源文全量重建流文档）
   阅读态 ──单击「编辑」──▶ 编辑态（释放渲染文档；编辑器内容零变化）
   ```

   **源文唯一**：阅读态从不回写；保存/防抖/合并管线不复制第二份。焦点治理：切入阅读态时若编辑器持焦，按既有焦点契约同链交还宿主窗（阅读视图不承载编辑保持原因）。
2. **刷新挂点四处**（与空状态同一挂点族，单点刷新函数）：模式切换／日期装载换文／程序性文本替换·外部变更·冲突合并三分支／文本变化（阅读态下源文只会被程序性替换，编辑态为空操作）。
3. **手势**：滚动/选中/复制＝阅读态全部手势；链接单击＝白名单内外部打开（下条）；无任何编辑手势——这是「只读」的操作面表达。
4. **链接白名单**：仅**绝对 URL 且协议为 http/https** 的链接可点击（手型光标＋强调色＋下划线）；其余（相对地址/其他协议）降级为普通文本呈现，不做任何导航。可点击链接交系统默认浏览器打开；打开失败（无关联程序/策略限制）**静默放弃**——链接点击是可重试的非关键路径，不值得打断阅读。
5. **语法子集与降级**：解析器只开核心语法（精确源位置）；超集结构不解析（天然按普通文本呈现＝安全降级）；不在子集内的节点（原始 HTML/图片等）按**源文切片**降级——不丢内容、不半解析、不解释标记。

## 四、动效编排

1. **切换无动画**：双态是状态语言（显隐瞬切），不加过渡——阅读的连续性由内容本身保证，转场反而打断视线。
2. **主题切换即时生效**：颜色全部活引用主题语义键（动态资源语义）——主题字典整本替换时阅读面随全窗即时换肤，禁止查找后快照持有（停旧色缺陷）。
3. 实验开关关闭＝零占位（切换条与阅读视图全部隐藏），无任何残留动效状态。

## 五、已知反例

1. **富文本注入面**：激活解析扩展（表格/脚注/原始 HTML）＝半解析与注入双风险；子集降级（源文切片呈现）是刻意的安全设计，不是能力缺失。
2. **流文档空格折叠**：普通空格序列会被折叠，代码缩进对齐丢失——代码行内空格以不间断空格代换。
3. **行内元素背景不渲染**：流文档的文本级节点不渲染背景，行内代码底必须由容器级元素承载。
4. **为 H4–H6 造第二份正文字号**：标题只设三档，H4–H6＝正文字号＋半粗权重区分——防字号表膨胀（同一数值两个身份也是双源）。
5. **代码字体并入界面字体**：代码字体是**独立功能槽位**（等宽、系统必装链、带回退），不随界面字体偏好变化；界面字体链按链首计行距度量，混用会带偏行高。
6. **给阅读面设显式行高**：阅读档不推行高 token——沿用字体自然行距（与卡片区显式推导行高的场景不同路）；字号即输入。
7. **键入焦点画默认虚线框**：阅读面非文本输入面，键入焦点不画系统默认焦点框（键盘滚动可达性保留）——焦点视觉治理见交互状态篇。
8. **阅读态持焦导致 Esc 语义漂移**：切入阅读态必须交还宿主焦点，否则「Esc 退出编辑保持」类宿主契约被阅读面劫持。
9. **软换行丢弃**：源文单行换行即换行（记录类内容的逐行习惯）；映射时软/硬换行一并映射为换行，不吞行。

2. **可移植要点**：
   - **双态同源**：编辑区与阅读区共享同一持久化文本；阅读渲染是纯函数 `text → DOM`，不回写、不复制状态；切换件用分段控件（单选语义，选中态用既有强调/活动色变量）。
   - **prose CSS 变量映射**：五个语义变量走全篇——主文字/次文字/强调/悬停面（代码底）/描边；深浅主题切改变量值即整篇换肤（等价活引用整本替换）。
   - **数值直搬**：正文 14、H1 20 / H2 17 / H3 15（示例值：typography.size.body / reading-h1 / reading-h2 / reading-h3）、H4–H6 `1em + font-weight:600`；块距 6（dimension.spacing.reading-block-gap）、代码内边距 8（reading-code-padding）、引用条 3（dimension.size.reading-quote-bar）；代码字体 `ui-monospace, "Cascadia Mono", Consolas, monospace` 独立变量（typography.family.code）。
   - **行为映射**：链接拦截——仅 http(s) 绝对 URL 放行外部打开，其余降级纯文本；软换行渲染为换行；代码块 `white-space: pre` 保缩进；图片不加载（离线）；不支持语法按原文降级段落，不半解析。
