# 范式·设置窗双栏 IA（Two-Pane Settings IA）

> **一句话定位**：设置窗信息架构配方——左单选导航组（选中态复用导航轨语言）＋右内容页常驻只翻可见性＋入场纯淡入、单一共享滚动视口（覆盖式滚动条防宽度跳变）、页脚非导航常驻、确定性键盘循环；页面永不重建，切换零状态丢失。**来源**：源项目 1.72.0 基线（commit `bba9b4e`）设置窗实证，经 `handoff/2026-11-11-bootstrap/PLAN-V1.md` §2.2 分片（B 裁决①：IA 与冻结几何拆分，本篇只收 IA；几何持久化一句话指向缺口登记）。**日期**：2026-11-12。**行数预算**：≤400 行（现 61 行）。

## 一、问题与适用

1. **问题**：设置项随产品增长必然超过一屏。三种常见坏解：单页长滚动（找不着）、每页独立窗口（上下文割裂）、动态销毁重建页面（表单状态丢失＋滚动位置丢）。本配方：**左导航＋右内容**双栏，页面**常驻可视树、只翻可见性**——切换是纯状态翻转，零重建零丢失。
2. **适用判据**：①页面数 3–9（超过 9 应考虑分组二级导航）；②页面间无强顺序依赖（导航自由跳转）；③页面内容以表单/说明为主（非向导流——向导需要受控顺序，不该用自由导航）。不适用：向导；单页能放下的设置（≤1.5 屏直接单页，不造导航）。
3. **设计立场**：设置窗的交互成本大头是「找到那一个开关」——一切结构决策（单选导航、常驻页、共享视口、键盘循环）都为「直达」服务。

## 二、结构分解

1. **三行骨架**：标题栏（拖拽区＋窗标题＋关闭钮）／双栏主体（左导航列固定宽 148，示例值：结构性尺寸；右内容列自适应）／页脚（滚动区外常驻）。窗体本身是无边框独立窗（几何规约与持久化是独立范式，本轮登记为缺口不展开，见 §六.1 末条）。
2. **左导航＝单选钮组**：
   - 原生单选钮组互斥（同组名）——不手写互斥状态；单选钮自带「选中项」语义与辅助功能角色，比自绘按钮列表免费获得可访问性。
   - 选中态**复用导航轨语言**：活动层底色＋强调色左指示条（3px，示例值：字面量）＋标签半粗；悬停＝悬停表面色。视觉语言与主界面导航轨同源，用户零再学习。纯文字导航项（无图标）——页面名自解释时不加图标（图标的辨识负担高于收益）。
   - 导航项高约 34、间距紧凑（示例值：命中区规格，按类型登记不 token 化，见形状与间距基础篇）；键入焦点不画系统默认焦点框（选中底色与指示条承载视觉——焦点治理见交互状态篇）。
3. **右内容页＝常驻面板组**：全部页是内容宿主内的**兄弟常驻面板**，初始可见性在声明期定死（默认页可见、其余隐藏）；切换只翻可见性。页面名常量表与导航项一一对应，切换处理器按名寻址。
4. **单一共享滚动视口**：全部页共享**一个**滚动视口（覆盖式滚动条，不占布局宽）——不是每页各自滚动。两个论据：①**宽度稳定性**：各页高度不同，占位滚动条的出现/消失会让内容列在「全宽」与「全宽−滚动条宽」间跳变，溢出页的卡片比不溢出页窄；覆盖式滚动条悬浮内容之上，各页卡片宽度在任何窗口高度逐像素相等。②**名字空间唯一性**：每页各自视口会要求每页独立命名挂点，破坏窗口单一名字空间下按名寻址与辅助功能树的直达性（切换机制本身就依赖按名寻址）。
5. **内容列对齐**：拉伸填充＋最大宽钳制（平台对受最大值钳制的拉伸自动居中）——**禁止**水平居中对齐（列宽会随最宽页收窄，五页内容不同宽→卡片宽度页页不等）。
6. **页脚＝非导航**：页脚承载关于（版本/链接/联系方式）与破坏性入口（退出），物理在导航组之外、无组名、非单选钮——**永不参与互斥、永不被选中**；常驻滚动区外。

## 三、状态机与手势

1. **页切换单点**：导航项选中事件 →按项标记取页面名→逐页「等于则可见、否则隐藏」→共享视口回页首（滚动偏移不跨页残留）→入场淡入。一个处理器管全部页，无逐页散挂。
2. **构造期陷阱与初始态**：声明期解析中途，首项的选中事件已触发而后续页尚未解析——寻址判空跳过，初始可见性完全依赖声明（不靠事件回放）。切页后缓存页面引用，此后按名寻址直达。
3. **键盘循环（确定性）**：↑/↓ 在**预览（隧道）阶段消费**并压掉单选钮原生方向导航（原生会一次跳多步，不可预测），保证一次按键恰前进一步；循环用取模（`(当前+偏移+总数) % 总数`）；Home/End 特判跳首末；目标项「选中＋聚焦」双置。Tab 不拦截（逐项停靠后流出导航组，原生行为）。全部箭头消费均在导航组容器上声明，不侵入页面区。
4. **手势面**：导航项单击＝切换（即时）；无长按/无右键（设置导航不需要二级手势）；页内交互归各页控件。

## 四、动效编排

1. **入场＝纯透明度淡入 167ms（示例值：motion.duration.normal）**：页切换只动透明度——可见性已即时生效（辅助功能与命中不依赖动画收尾），淡入纯装饰。**不用**主界面导航轨的 120ms 位移显现（示例值：motion.duration.category-reveal＋位移）——场景不同不搬编排：设置页切换是「平级翻页」，无「内容从轨下拉出」的语义，位移反而暗示错误的方向关系（档位与缓动的场景锚定原则见动效篇）。
2. **退化**：窗口未加载完成或减动效＝直接就位不播淡入。
3. 无其他动效：导航选中态、指示条、悬停全部瞬切（状态语言）；设置窗整体克制——它是「工具间」，不是舞台。

## 五、已知反例

1. **每页独立滚动视口**：滚动条占位导致内容列宽度在页间跳变（溢出页更窄）；且命名挂点分裂破坏按名寻址。对策＝单一共享视口＋覆盖式滚动条（滚动条双宿主的完整范式见表面类范式篇）。
2. **内容列水平居中**：列宽随最宽页收窄→各页卡片宽度不等（实测根因修订）；对策＝拉伸＋最大宽钳制。
3. **切页保留滚动位置**：共享视口下滚动偏移跨页残留＝新页从中间打开；对策＝切页显式回页首。
4. **单选钮原生方向键导航**：一次按键跳多步（焦点链不可预测）；对策＝隧道阶段消费＋取模循环。
5. **声明期依赖事件回放定初始态**：首项选中触发时后续页未解析，按名寻址落空；对策＝初始态声明期定死＋判空跳过。
6. **窗体最大尺寸走属性钳制**：平台属性钳制在极值区间会与最小值互锁出「缩放死区」（历史版本实测教训）；上限改经系统消息轨道强制。上限小于下限在同一平台是未定义行为（矮屏按最小值抬升）。
7. **页脚进导航组**：页脚项可被选中＝「退出」变成导航态（荒谬且危险）；页脚物理隔离＋无组名。
8. **导航项加装饰图标**：页面名已自解释时图标只增加辨识负担与维护面（图标尺寸/字形是另一套豁免体系）。

2. **可移植要点**：
   - **Web 等价**：左导航＝`role="radiogroup"`（或 tabs 模式 `tablist/tab/tabpanel`）——原生互斥对应 `aria-checked` 单选语义；键盘＝roving tabindex＋环回箭头（取模循环可逐字移植）、`keydown` 里 `preventDefault()`（等价隧道消费）；页面常驻只翻可见性＝路由切换**不卸载面板**（`visibility:hidden` 切换而非条件重挂载，保留组件树与表单状态）——对应框架里的「keep-alive」策略；共享视口＝单一滚动容器＋`scrollbar-gutter: stable` 或覆盖式滚动条（宽度跳变的 Web 镜像对策）；切页回页首＝显式 `scrollTo(0,0)` 并关闭滚动恢复。

   - **尺寸口径**：导航列宽/窗体默认与极值全部为冻结几何（结构性尺寸，不 token 化——「结构不为内容让步」）；唯一声明点单文件，多窗消费走常量引用。
