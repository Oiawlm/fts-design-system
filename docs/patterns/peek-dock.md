# 范式·贴边停靠（Edge Dock / Edge Peek）

> **一句话定位**：常驻侧边工具窗「让出屏幕但保留存在感」的完整配方——整窗平移收缩为屏内 16px 把手、三相位状态机（Idle→Armed→Peek）与放置动画层分离、60ms 悬停意图事务、途中反向救援（禁原点重放）、停靠意图互斥组与「一次迁移一次变更」原子性。**来源**：源项目 1.72.0 基线（commit `bba9b4e`）一次性贴边隐藏实证，经 PLAN-V1（对账 [2026-11-fts-v1.72.0.md](../../reference/extractions/2026-11-fts-v1.72.0.md)） §2.2 分片。**日期**：2026-11-12。**行数预算**：≤400 行（现 100 行）。

## 一、问题与适用

1. **问题**：悬浮工具窗不用时要完全让出屏幕，但**不能失去找回路径与存在感**。传统做法（缩到托盘/最小化）丢上下文；半透明驻留则永久占地。本范式：**整窗同尺寸平移收缩**，屏内只留一条全高把手（宽度 16px，示例值：dimension.size.peek-handle-width），悬停把手即展开回原位——「藏起 95%、留住 5%」。
2. **适用判据**：①常驻型侧边工具窗（非模态、单实例）；②收缩是**平移**不是变形（宽高恒不变，矩形不变量可被锁定测试断言）；③需要可单测的纯逻辑相位机＋独立动画服务。不适用：对话框（无驻留语义）、多窗口停靠布局（那是 dock layout 系统，不是单窗让位）。
3. **三个硬约束**（本配方的设计起点）：不透明系统材质窗**没有整窗透明度**，把手命中区与视觉必须同源；动画期间窗口矩形的**权威只能有一个**；用户随时反悔（收缩途中追进来）必须能**无缝反向**。

## 二、结构分解

1. **把手层**：屏内保留的全高竖条。关键不变量＝**视觉宽＝命中宽＝屏内保留宽三值同值**（收缩后窗口与工作区交集宽恰为把手宽）——不透明窗没有「透明命中区」可用，三值解耦会在屏内露出内容切边。把手自带悬停提亮层（独立反馈层，不参与相位机）。
2. **双层状态机**：**相位层**（纯逻辑、零界面依赖、可单测）只记「是否已收缩驻留」三相位；**动画进行态**由独立的**放置动画服务**承载——逐帧插值＋平台级纯平移帧（宽高恒不变，绕开属性系统），动画期间**窗口矩形权威归动画服务**，界面属性账本只在动画完成或取消时**一次收口**。
3. **意图计时器**：把手悬停展开走「布防→计时→到期重验」事务（§三.3），计时器在窗口层、不在相位机内。
4. **互斥组**：与本范式并列的「驻留锁定（hold-open）」构成**停靠意图互斥组**——横切两台状态机的协调事实，独立单点持有，不塞进任何一台状态机（否则互相越界知晓）。
5. **计时器族分工**（全部在窗口层）：收起驻留计时（指针离开→到期收起，250ms＝慢档 token 同源）；意图计时（60ms）；两者与相位机通过谓词交互。

## 三、状态机与手势

1. **相位状态机**（Idle／Armed／Peek，会话级、不持久化——重启永不恢复成离屏态）：

   ```
   ┌────────┐  头部按钮(武装)   ┌────────┐  指针离开→驻留计时到期(250ms) 且收起抑制不成立
   │  Idle  │ ───────────────► │ Armed  │ ─────────────────────────────────────┐
   │        │ ◄─────────────── │        │ ◄──── 抑制成立：留在 Armed 等下次 ──┘│
   └────────┘  再按一次(取消)   └────────┘            一次性授权被消费           ▼
      ▲ ▲                            │                                      ┌──────┐
      │ │        Reset（防悬置）      │ Reset（被互斥组挤出/面板经他路收起）    │ Peek │
      │ └────────────────────────────┴────────────────────────────┐         │      │
      │                                                            │         └──────┘
      └──────────────────────── Reset（把手意图事务提交/热键/显示器变化/外部拖放揭示）──┘
        （Peek 态下按钮不可达：武装切换＝防御 no-op，不变相位）
   ```

   | From | 事件 | 守卫 | To | 备注 |
   |---|---|---|---|---|
   | Idle | 武装切换 | — | Armed | 返回 true；同步向互斥组申请 |
   | Armed | 武装切换 | — | Idle | 返回 false＝再按取消；清互斥＋恢复自动收起节奏 |
   | Armed | 提交收缩（收起计时到期） | 收起抑制不成立 | Peek | **一次性授权被消费**；抑制成立则留 Armed 等下次离开重试 |
   | Peek | 解除（多出口共用 Reset） | — | Idle | 见下「解除出口」 |
   | Armed | 解除（防悬置） | — | Idle | 面板经其他路径离开展开态／被互斥组挤出 |
   | Peek | 武装切换 | — | Peek | 防御 no-op（把手态按钮不可达，防误当取消） |

2. **提交时机复用既有收起节奏**：不新增触发器——融入「指针离开→驻留计时（250ms）→到期 tick」的既有链路，tick 内若已武装且抑制不成立则走贴边收缩而非普通收起。**收起抑制谓词**与面板收起复用同一套（指针在内／拖拽在途／文本编辑中／驻留锁定激活，任一成立即抑制）——抑制条件不在相位机内另立一套，由调用方求值后以布尔传入（状态机保持零依赖）。
3. **60ms 悬停意图事务**（到期重验）：指针进入把手/窗口→**布防**计时；提前离开→取消；**到期重验**＝仍处于 Peek **且**系统指针位置仍在窗口矩形内（含把手）才提交展开，否则本次意图作废、等下次进入重新布防。防扫边误触由事务重验达成，**不另设防抖层**。
4. **解除出口（Peek→Idle）四条共用一个记账单点**：①把手意图事务提交；②全局唤起热键；③显示器/工作区变化（离屏窗口在新布局下可能失去找回路径，立即展开防「找不到窗口」）；④外部拖放轨揭示。共同动作＝相位复位＋清互斥＋停意图计时＋藏把手＋刷按钮态。
5. **意图互斥组**（成员：无／驻留锁定／贴边停靠；会话级）：**后激活者胜**——激活任一方即解除另一方，两入口任何时刻不同时点亮（视觉态与功能态一致）。登记＝申请并返回被挤出的旧意图（空态或同意图幂等再激活返回空）；释放＝**条件解除**，仅当当前持有者恰为该意图时才清空——被挤出意图的解除路径晚到时不得误清新持有者。注意：互斥挤出**不负责唤回**已离屏窗口（那是解除出口的事）。
6. **恢复兜底**：启动时不持久化离屏态；所有放置从「当前工作区」推导＋钳制回屏内（持久化的只有高度/宽度/顶距等归一量，钳制到工作区），显示器变更后旧几何不可能把窗口留在屏外。

## 四、动效编排

1. **数值考据**（哪些是 token、哪些是豁免——口径必须分清）：

   | 值 | 性质 | 出处口径 |
   |---|---|---|
   | 16px 把手宽 | **token**：dimension.size.peek-handle-width | 8–16 经验区间取上沿（全高竖条好命中）；三值同值不变量＋镜像锁定测试互锁；不透明窗无透明命中区是三值约束的物理根因 |
   | 250ms 展开 | **token**：motion.duration.slow（直接引档，非场景别名） | 复用三档不加档；配减速进入曲线 motion.easing.enter |
   | 167ms 收缩 | **token**：motion.duration.normal（直接引档） | 配加速离开曲线 motion.easing.exit；**缓动按语义选**（进入视觉态＝减速、离开＝加速），位移方向不决定曲线 |
   | 250ms 收起驻留 | **token 同源**：motion.duration.slow | 终态化口径：原为行为计时器字面量，后裁决**引慢档 token 同源**（豁免表除名在案）——驻留节奏与展开时长同源 |
   | 60ms 意图窗 | **行为计时器豁免**（入常量但不属视觉档） | 意图判定窗口是时序编排值非视觉档位；另有同值的面板展开意图窗字面量，**同值异义、明令禁止共用**（各自豁免依据独立登记） |
   | 83ms 把手淡入 | **token**：motion.duration.fast | 把手层入场淡入（整窗透明度不可行，柔和收束由把手层达成） |
   | 167ms 把手悬停提亮 | **token**：motion.duration.hover-feedback | 独立反馈层 |

2. **反向救援（Redirect）**：收缩进行中指针追入→意图事务到期重验通过→展开救援——若动画在途则**捕获当前实时进度为新起点**、时长按剩余距离比例重映射（封顶满时长 250ms），**禁止原点重放**（绝不让窗口先跳回段起点再重播——那是倒带视感）。无在途动画则直接从当前系统矩形起算新段。**不对称性**：收缩可被打断反转；**展开途中不中断**（完成后续接常规 250ms 收起节奏）。
3. **动画服务语义**：开始＝先取消在途（不落终态，由新段起点接管）、首帧立即应用、末帧精确落终态；取消＝交还矩形权威，可选一次直达终态（「经终态的权威交接」），**取消不回调完成事件**（完成回调恰一次，由正常末帧触发）。
4. **迁移原子性与例外通道**：「一次迁移一次变更」——非动画迁移只允许一次窗口矩形变更（观察到的每个矩形∈{初始，终态}），对齐账本期间的中间矩形改写由守卫拦回终态。**唯一例外通道**（连续动画迁移允许中间矩形）须同时满足五条款：①单一矩形权威（任何放置入口先取消动画到达终态再应用）；②逐帧单调；③终态唯一（末帧精确落位、完成恰一次）；④可中断可重定向（禁原点重放）；⑤减动效直达（减动效时不进通道、直达终态）。本范式的平移动画是通道唯一合法居民——条款与动效篇「例外通道」节同源，彼处立总规则，本篇只消费不复述。
5. **减动效退化**：全链直达终态（无飞行帧），把手层直接就位。

## 五、已知反例

1. **原点重放**：反向时若从段起点重播＝倒带视感；必须以当前实时进度为起点比例重映射（锁定测试断言反转起点＝当前实时位置）。
2. **动画期间矩形权威撕裂**：动画在途时其他代码径直改窗口矩形＝权威撕裂；一切放置必须经统一入口先取消动画（直达终态）再应用。装饰性掩盖（区域裁剪/延迟/藏窗）禁止。
3. **整窗透明度幻想**：不透明材质窗没有整窗透明度，「淡出尾巴」对窗本体不可实现；柔和收束改由把手层入场淡入承载。
4. **把手淡入基线写反**：入场 0→1 的基线必须落在终值 1，写反＝淡入结束后把手整体隐形（实测根因）。
5. **扫边误触**：命中即展开必误触；意图事务＋到期重验根治，不加防抖层。
6. **Peek 态被误收起**：离开/计时双重防御——Peek 态不启动收起计时、计时 tick 对 Peek 态直接返回（防自动化路径误触发）。
7. **Peek 态被误当取消**：武装切换在 Peek 态是防御 no-op——窗口只剩把手，按钮物理不可达，任何到达的切换都是异常路径。
8. **同值异义共用**：把手意图窗与面板展开意图窗同值（60ms）但语义不同，禁止共用常量——共用后改一处必污染另一处。
9. **快拖读陈旧宽度**：尺寸拖拽读上次布局实际宽度会把末帧误差固化为边缘空隙/越屏；目标矩形统一经原子推导通道。
10. **输入法候选窗造成的假离开**：编辑交互期指针「离开」多为候选窗遮挡的假信号，吞掉不落离开面（收起抑制同族）。
11. **互斥晚到解除竞态**：被挤出者的解除晚到时不得误清新持有者（条件解除根治）。
12. **绝对坐标持久化**：持久化绝对坐标＝换显示器后窗口丢屏外；只持久化归一量＋工作区钳制。
