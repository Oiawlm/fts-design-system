# 范式·实验开关体系（Experiment Toggles）

> **一句话定位**：打磨期能力的灰度容器——自绘开关＋「按成熟度定默认态」判据、节内逐项说明实验原因、构造期回显守卫、默认值版本化一次性迁移（版本戳门控/幂等/IO 自愈）与毕业/退役路径；让「实验」成为有生命周期的容器而非永久标签。**来源**：源项目 1.72.0 基线（commit `bba9b4e`）实验性设置节实证，经 `handoff/2026-11-11-bootstrap/PLAN-V1.md` §2.2 分片。**日期**：2026-11-12。**行数预算**：≤400 行（现 79 行）。

## 一、问题与适用

1. **问题**：产品迭代中大量能力处于「能用但不稳」的中间态。两难：默认开＝把不成熟强加给所有人；默认关＋藏在开发者选项＝永远没人用、收不到反馈。需要的是**按能力各自定默认态的灰度容器**＋一套让能力「进来—打磨—毕业（或退役）」走完生命周期的机制。
2. **适用判据**：①能力独立可开关（开/关不影响其他能力的正确性）；②默认态是**产品判断**（成熟度）而非技术判断（是否安全）；③存在明确的毕业判据（如「连续两个版本无语义修订且无报障」）。不适用：安全/隐私相关开关（默认必须保守且**披露常可见**，见 §二.3）；技术上未完成的功能（不该有开关，直接不发）。
3. **核心机制三角**：判据（默认态怎么定）＋迁移（改默认值时老用户怎么办）＋毕业（怎么离开实验节）——缺一即退化成「永久实验堆」。

## 二、结构分解

1. **自绘开关**（不依赖平台默认开关貌）：轨道（40×20 胶囊，示例值：结构性尺寸；圆角＝高一半，胶囊派生规则不入圆角阶梯，见形状基础篇）＋滑块（14×14 圆，圆角＝高一半）＋勾选语义色（开＝强调色轨道＋强调色上前景滑块；关＝默认描边色轨道＋次级文字色滑块）。悬停＝**仅描边**轻反馈支系（不换底、不位移）；按压无独立态；禁用＝整控件不透明度 0.4（示例值：motion.opacity.control-disabled）。**状态瞬切无动画**——开关是状态语言不是动效语言；可访问名称逐处显式声明。
2. **节结构三层**：
   - **节头＝判据式文案**（不罗列默认值快照）：「按成熟度各定默认态（各项默认值与打磨原因见行悬停说明）；调整立即生效并自动保存」——默认值快照写进节头会与文档双写漂移（见 §五.2）。
   - **行三层**：行标题（挂悬停说明：默认值＋为什么实验——「默认开启：××仍在打磨，不合意可关闭」/「实验性功能，默认关闭：××」两种句式）＋说明行（一句「开启后……」效果句）＋多值项用下拉枚举（枚举设置一律下拉，不造三态开关）。
   - **归置规则**：无领域依赖的能力进通用实验节；依赖领域配置的（如需密钥）留领域页并标注「实验性」。
3. **披露红线**：隐私与数据外发、默认值变化、不可逆操作三类信息**必须常可见**（行内/节内明示），不得只收进悬停说明。
4. **偏好通道**：开关即点即生效＋立即持久化（无「保存」按钮、无确认弹窗）；全部经**唯一应用管线**做不可变更新＋原子落盘，禁止平行保存路径。

## 三、状态机与手势

1. **开关即生效**：单击＝翻转＋应用＋保存，一次手势三件事；无中间态、无待提交态。
2. **构造回显（同步段）**：设置窗构造时**直赋回显**（非双向绑定）：进入同步段（置同步标志）→逐控件把当前偏好值直赋到 IsChecked/选中项 →退出同步段。每个变更处理器首行查同步标志**早退**——程序化回显不触发二次保存，只有用户操作走应用管线。下拉按数据值匹配（不依赖选项下标）。
3. **默认值版本化一次性迁移**（改默认值时的老用户收敛机制）：

   ```
   启动装载偏好 ──▶ 版本戳 ≥ 当前迁移版？ ──是──▶ 原引用返回（零写盘、幂等出口）
                        │否
                        ▼
                 不可变更新：目标键置新默认值 ＋ 版本戳＝当前迁移版
                        │
                        ▼
                 经唯一存储管线原子落盘
                        │失败（IO/权限）
                        ▼
                 采纳带戳内存基准继续启动（盘上无戳→下次启动重放；
                 期间任意一次偏好保存把戳随快照自愈落盘）——收敛保证
   ```

   四性质：**门控**（戳单调，已迁移者永不重放）；**幂等**（重跑无副作用、逐字节零重写）；**IO 自愈**（写失败不阻断启动，最终必然收敛）；**一次性语义**（迁移后用户的显式选择永不复翻）。调用时点＝启动装载之后、主窗构造之前（功能面单一下发路径；「启动只读不写」原则的唯一例外族＝一次性版本戳迁移）。
4. **毕业与退役**（实验开关的出口，两条都有先例）：
   - **毕业为默认开**：默认值 false→true＋构造默认翻新＋存量显式 false 经一次性迁移统一置开（歧义代价公示，见 §五.1）；偏好字段名毕业前后不变。
   - **退役**：方向被推翻时**删开关**、行为恒定化；残留偏好字段按未知成员忽略（不迁移、不回落任何语义）——字段自然淘汰。
   - **在册约束**：无存量状态的新开关不进迁移（无状态可变换）；实验节空置不删节（容器复用）。

## 四、动效编排

1. 开关本体**无动画**（瞬切）：实验开关的高频用途是「试一下不喜欢马上关」，任何过渡延迟都是摩擦。
2. 悬停仅描边切换（颜色瞬切，不带时长）；反馈语言与交互状态篇的「密集控件只换边」支系一致。
3. 禁用＝不透明度档（0.4，示例值：motion.opacity.control-disabled），复用全局禁用档，不为开关另设。

## 五、已知反例

1. **直接改构造默认值而不做迁移**：老用户已落盘的显式 false 与「从未设置」无法区分——默认翻转后要么全部突变（激怒用户）、要么永不收敛；正确做法＝默认值版本化一次性迁移，且把「自动落盘的显式关闭也会被翻开」的歧义代价**公示**（全量快照持久化的固有代价，用户接受后才实施）。
2. **节头罗列默认值快照**：与使用文档同语义双写，「每翻默认值两处必改」必然漂移；节头只写判据，默认值进行级悬停说明。
3. **悬停说明挂接点不统一**：行标题/说明行/节标题三处并存无判据，导致关态残留开态说明；统一挂行标题（或节标题）单点。
4. **退役开关残留字段做回落**：被删开关的旧字段若被解析回落，等于复活已否决的方向；按未知成员忽略。
5. **新开关即进迁移**：无存量状态的新键进迁移＝迁移体膨胀且语义空洞；只迁移「存量显式值会被新默认翻转」的键。
6. **平行保存路径**：开关各自为政直接写配置文件＝绕过原子写与不可变更新，损坏偏好文件；必须经唯一应用管线。
7. **隐私句收进悬停**：外发类能力的披露只在悬停说明＝隐藏披露；三类红线信息常可见（§二.3）。
8. **构造回显用双向绑定**：绑定回路在装载期触发变更事件，回显守卫失效或保存竞态；直赋＋同步段早退最简且可证。

2. **可移植要点**：
   - **Web/localStorage 等价**：偏好全量快照存单键＋独立整数版本戳字段（缺省 0）；启动单函数门控 `if (stamp >= CURRENT) return prefs;`（同引用返回零写）→展开生成新对象（改键＋戳）→单一原子写路径（写临时键＋改名，或至少 try/catch）；幂等靠戳单调；自愈靠「写失败带戳续跑、下次重放」；未知字段容忍＝解析后只取已知键，删的字段自然淘汰。
   - **歧义代价的替代**：快照式存储的「隐式关 ≠ 显式关」固有歧义，Web 更易做增量式——只存用户显式设置过的键（不写键＝跟随默认），默认值翻转天然不需要迁移；若保持快照式，则公示一次性翻转代价。
   - **状态/UI 分层**：迁移器是纯逻辑类（输入偏好对象＋存储接口，输出新对象），五态可单测；开关视觉层零迁移知识——生命周期机制与控件完全解耦，任何栈可复用。
