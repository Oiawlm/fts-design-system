# 范式·容器变换弹层（Container-Transform Overlay）

> **一句话定位**：小元素↔大容器连续性转场的全配方——四变换同帧启动使「矩形插值」成为结构性质、文字后段浮现（fade-through 口径）、三段线性收回＋交叉淡化保持落位点存在感恒≈1、几何测量剥自身渲染变换、独立时长组的契约化登记；实证载体为二维码缩略图→放大层。**来源**：源项目 1.72.0 基线（commit `bba9b4e`）二维码放大层实证，经 PLAN-V1（对账 [2026-11-fts-v1.72.0.md](../../reference/extractions/2026-11-fts-v1.72.0.md)） §2.2 分片。**日期**：2026-11-12。**行数预算**：≤400 行（现 114 行）。

## 一、问题与适用

1. **问题**：界面里同一内容有两个呈现宿主——角落的小缩略图与全幅放大层。朴素做法是「小图淡出＋大层淡入」（内容凭空消失再出现）或生硬弹窗。容器变换（container transform）要求**视觉连续**：小矩形「生长」为大矩形，内容在容器落位后浮现，收回时反向回到原位——用户始终知道「它从哪来、回哪去」。
2. **适用判据**：①同一内容双宿主（缩略图↔放大层、列表项↔详情页、按钮↔展开面板）；②源与目标**几何不同族**（本实证为方→高矩形，非等比）；③转场是**重操作**（用户主动触发、独占注意力），值得独立时长组。不适用：轻量反馈（用三档体系即可）；无固定源几何的泛型弹窗（没有「从哪来」）。
3. **本配方的独特主张**：①不用「缩放＋平移两套动画凑巧对称」，而是四条显式插值同帧启动，把矩形连续性做成**结构性质**；②收回期设计成「看得见地回到原位」，交接段用等斜率交叉淡化保证任意时刻总存在感≈1；③全部数值带**外部文献出处**并独立成组，与通用三档隔离。

## 二、结构分解

1. **三层结构**（放大层自上而下）：
   - **遮罩纱**：半透明压暗层，承载「转场期间背景退场」；入场与容器同帧淡入、收回与容器同曲线同时长淡出（一个节奏收回，末段无骤曝）。
   - **放大卡容器**：**布局层与渲染变换分离**——容器在布局树一次到位（目标尺寸恒定，动画不改布局矩形，零回流）；飞行由代码后置构造的「缩放＋平移」渲染变换组驱动。容器自身再拆**阴影层＋内容面**两子层（阴影随高程语言走共享样式）。
   - **源缩略图**：触发钮（含框外接矩形即源几何），飞行期间作为「原位存在感」参与收回交接（§四.3）。
2. **内容面三元素**：标题/主内容/脚注——**布局恒占位、透明度基值为 0**：飞行期不可读也不随容器缩放呈现，落位后段才浮现（§四.2）；布局占位保证浮现零回流。
3. **岛式码面（主题豁免登记）**：扫码面的恒白底是**物理约束**（可扫性）而非调色板颜色——按配色豁免清单登记为主题不变量；深色主题下用主题阴影高程把白底码面「岛」式抬出暗背景（放大层与页脚缩略两宿主同规则）。
4. **生命周期守卫**：代数计数（generation）——每次开层/关层自增，掉队的完成回调按代数作废（防「再开被旧回调塌缩」）。

## 三、状态机与手势

1. **层生命周期**（无嵌套模态，单层）：

   ```
   关闭 ──触发钮单击/Enter──▶ 展开飞行(450ms) ──完成──▶ 驻留(全显终态)
   驻留 ──Esc/单击任意处/触发钮再按──▶ 收回飞行(250ms) ──完成(单一完成点+代数守卫)──▶ 关闭
   展开飞行中再触发 ──▶ 不中断：自当下渲染矩形续走（动态 From 是结构性质）
   收回飞行中再触发 ──▶ 新生命周期代数自增，旧回调作废
   ```

2. **手势语义**：Esc＝只关层（与「单击任意处关闭」同语义，**不顺带关闭宿主窗**——一层只担一层的事）；单击遮罩/任意处＝关层；触发钮＝开/关两态。
3. **可中断口径**：入场 From＝**当下实测渲染矩形**（不是上次快照）——「快照即替换」式中断，任何时刻可被新交互替换；判定「飞行中」＝四变换任一偏离恒等。

## 四、动效编排

1. **数值考据**（全部数值的**外部文献出处**——引源项目 token 注释原文考据，逐字引文见 §六.2）：
   - **入场曲线** (0.32, 0.72, 0, 1)（示例值：motion.easing.qr-zoom-in）＝iOS 导航/照片缩放转场的**非官方测量近似**（出处标注为 ionic-framework issue #19789 的社区测量，源注释未引 iOS 版本号或大会条目——考据到此层为止，不作更具体归属）。
   - **收回曲线** (0.25, 0.1, 0.25, 1)（示例值：motion.easing.qr-zoom-out）＝Apple 公开缺省缓动 `kCAMediaTimingFunctionDefault`（QuartzCore 官方文档在册）。
   - **时长与文字编排**＝Material 转场规范两条目：container transform（时长量级）与 fade-through（文字后段进场口径）。
   - **实验校准口径**：终值以真实录屏迭代微调收敛（时长带、进度带、控制点带），回写 token 与契约登记——「先文献定初值、再实测收敛、终值回写」是独立组数值的完整生命周期。
2. **展开 450ms（示例值：motion.qr.zoom-in）**：

   ```
   ms   0                    容器四变换同帧启动（同 duration＋同缓动＋同帧）
        ├ ScaleX: 源宽/卡宽 → 1   ┐ 「视觉矩形 from→to」同一进度 p 驱动
        ├ ScaleY: 源高/卡高 → 1   │ ScaleX≠ScaleY 承载方→矩形非等比形变
        ├ TranslateX: 中心差 → 0  │ 布局一次到位恒定，动画不改布局矩形
        └ TranslateY: 中心差 → 0  ┘
   0    遮罩纱 0→1（83ms，motion.duration.fast）；卡片 0→1 同帧同曲线（兄弟不相乘）
   0    缩略图 当下值→0（150ms，motion.qr.thumb-fade·防双影淡出）
   0–270 文字三元素 基值 0（布局恒占位，飞行期不可读不缩放呈现）
   270  ██ 文字 0→1 起（180ms，motion.qr.text-fade-in；起点 270＝450×60%，示例值：motion.qr.text-fade-in-begin）
   450  容器落位恒等＋文字恰同帧全显（落位时可读）
   ```

   要点：①**四动画同帧启动＝矩形插值是结构性质**——四分量（缩放两轴＋平移两轴）同 duration 同缓动，则视觉矩形逐帧恒等于对源/目标矩形四分量按同一缓动的插值；对称往返不靠「两套动画凑巧对称」。②**文字 60% 进度后段浮现**＝fade-through 的迟到进场：容器落位后段（60%→100%）文字才淡入，落位即可读；文字从不随容器缩放呈现（避免缩放中的文字变形）。
3. **收回 250ms（示例值：motion.qr.zoom-out）——三段线性＋交叉淡化**：

   ```
   ms   0            容器自当下渲染矩形→当下实测源矩形（收回曲线）
   0    遮罩纱 1→0（同曲线同时长收回）
   0–90  文字 当下值→0（90ms，motion.qr.text-fade-out·先隐）；卡片 当下值→1（归位段）
        缩略图 当下值→0（清除段·杀中途半显值）
   90–180  卡片持稳 1（飞行期全程可见——「看得见地回到原位」）；缩略图持隐 0
   180  ◆ 缩略图回显起点（收回曲线反解 95% 回程≈0.722×250→180，示例值：motion.qr.thumb-reveal-begin；
          容器已≈1.05× 落位尺寸，此前持隐防飞行中段双影）
   180–250 交接段（70ms，示例值：motion.qr.handover-fade＝收回时长−回显起点，差值声明）：卡片 1→0 ⇄ 缩略图 0→1
            同窗等斜率线性交叉 ⇒ 任意时刻 合成存在感恒≈1（无台阶/空窗/双影）
   250  单一完成点（平移动画 Completed＋代数守卫）→ 层塌缩复位
   ```

   要点：①**收回关键帧全线性**（透明度轨道不用缓动曲线——交叉段的等斜率是合成≈1 的代数前提）；②**交接起点由曲线反解**：收回曲线输出达 95% 的时间点（容器已≈落位）才让原位元素回显——对缓动函数数值反解选交接窗，是可复用的方法论；③卡片归位段与文字先隐共用 90ms 是**同族时长复用**（同一「先隐」语义族），交接段 70ms 则以**差值表达式**声明（终值恒等锁定，改总时长自动跟随）。
4. **几何测量剥自身渲染变换**：测源矩形时必须**剥掉容器自身渲染变换的当下缩放态**——坐标变换 API 会穿过容器自身的渲染变换，动画进行中直接测量会被自身动画污染（放大误差）。方法：源钮经坐标变换取外接矩形；容器布局原点（与渲染变换无关）＝含变换的原点变换**减去平移分量**（绕原点缩放下 (0,0) 只随平移移动）；源矩形＝二者之差。测量失败/零尺寸/非有限值→返回空，调用方走退化路径。**不缓存**测量结果（滚动/移动后收回仍回当下位置）。
5. **退化路径**：①减动效＝跳过编排、三对象**定格全显终态**（不用长淡出替代）；关层＝即时塌缩到静止基值。②动效开但测量失败/几何非法＝容器**快照当下值定基后清动画**（定格在飞，禁瞬时归恒等——那是「居中放大位原位闪现」单点故障）、卡片自当下值线性淡出整段收回时长、缩略图同窗线性归 1，终态与正常路径逐值一致；单一完成点带代数守卫。③飞行中再开＝自当下渲染矩形续走。
6. **独立时长组的契约化登记**：整组时长/曲线**独立成组**——不并入通用三档、不加第四档（档位制红线）、也不被组外场景借用。合法身份的取得条件：①登记设计契约；②给出**外部数值依据**（本组＝前述三源文献）；③实验期允许组内微调而不污染三档。通用三档与其场景别名体系见动效篇档位节；「例外通道」总规则在动效篇例外通道节——本组是时长面的契约化例外（彼处立规、本篇例证，闭环互引）。组内有一枚**互锁契约常量**（交接段＝差值表达式）：运行时零消费、仅由锁定测试断言恒等——它是防未来手改漂移的自文档化护栏，不是死代码。
7. **入场防双影**：开层期缩略图自当下值淡出（150ms，示例值：motion.qr.thumb-fade）——放大卡已呈现同一内容，缩略图不隐会双影；收回期回显时点则由反解编排（见 §四.3），两处不用同一常量。

## 五、已知反例

1. **卡片可见度被遮罩曲线绑架**：把淡出挂在遮罩纱的可见性上（父子相乘）＝原位闪现根因——结构拆分：根层只管布局/命中/生命周期，卡片自持可见度。
2. **先淡出后缩的空窗**：收回若「内容先淡没、容器再缩回」＝中段空窗；本配方反此道——卡片全程可见飞行，交接段交叉淡化。
3. **双影**：放大层与缩略图同屏同时半显＝双影；入场防双影淡出＋收回持隐至 95% 回程两处各自治理。
4. **末段骤曝**：遮罩收回曲线与容器不同（更快结束）＝末段背景骤然全亮；遮罩收回必须与容器同曲线同时长。
5. **错帧闪窗**：四变换分四帧启动＝矩形撕裂一瞬；同帧启动把错帧**结构性关闭**（不是「调小心点」）。
6. **掉队回调塌缩**：旧生命周期的完成回调在新会话进行中触发＝层被误塌缩；代数守卫三处（开层/正常完成/退化完成）。
7. **双重变淡**：容器淡入与其子卡片淡入相乘＝比设计暗一倍；父子轨道同帧同曲线＝「兄弟」关系，透明度不相乘。
8. **省略 From 瞬跳**：出场动画省略起始值＝自基值起跳（中断后基值≠当下视觉值）；一切出场 From 必须显式取**当下实测值**。
9. **基值残留**：上一会话定格的基值 1 未清＝下次入场前闪现；入场前做基值卫生（清动画置 0）。
10. **过期时长残留**：退化路径沿用上次会话的时长快照＝节奏错乱；时长复位先于测量判定。
11. **测量被自身动画污染**：飞行中经坐标变换 API 测容器＝读到放大后的值；测量必须剥自身渲染变换（§四.4）。
12. **无节制的独立组**：任何场景觉得「三档不合适」就开独立组＝档位制崩溃；独立组是极少数契约化例外，须登记＋外部依据（§四.6）。

3. **可移植要点**：
   - **Web/FLIP**：测量剥变换＝FLIP 首步（先取首帧矩形再挂变换）；「同一进度驱动四分量」＝单条 `transform: translate() scale(sx, sy)`（非等比承载形变）＋中心差平移（或变换原点技巧，两法等价、注意与反推互逆）；曲线直抄 `cubic-bezier(0.32,0.72,0,1)`／`cubic-bezier(0.25,0.1,0.25,1)`。
   - **View Transitions API**：源与目标同名 `view-transition-name` 的快照变形原生即容器变换；默认整组交叉淡化，需覆写 `::view-transition-group()` 动画（时长/曲线）与新旧快照层——文字后段浮现对真实元素加 `transition-delay: 270ms`（快照内元素不可独立动画；「文字布局恒占位」提示 to 态布局内应占位）。
   - **可中断**：Web Animations 新动画天然替换同属性旧动画（等价快照替换式中断）；「新状态先复位终值再挂动画」＝先 `commitStyles` 再 play。
   - **交叉淡化≈1**：两条等斜率线性透明度交叉，多关键帧 `offset`＝180/250→0.72/1.0 直接复刻；「95% 回程反解」方法论＝对缓动函数数值求 x 使 y≈0.95。
   - **减动效/测不到**：`prefers-reduced-motion` 直落终态（勿用长淡出替代）；测量失败 fallback 纯淡出（快照当下值定基）。
