# 哲学·六原则（Philosophy）

> **一句话定位**：整套体系的价值观层——把「可预测性」置于「惊艳感」之上、把「系统可治理性」置于「局部最优」之上的六条设计原则，每条按「陈述→第一性依据→落地判据→反例信号」四段书写，全部已知反例的展开见 [anti-patterns.md](anti-patterns.md)。**来源**：源项目 1.72.0 基线（commit `bba9b4e`）实践提炼——skill 哲学六条为直系材料，逐条仓库出处经源项目溯源报告 §一 核验，本篇锚点行按同一基线实测复核（抽查记录见本地 handoff/REPORT-E4）。**日期**：2026-11-12。**行数预算**：≤280 行（现 122 行）。

## 〇、整体美学立场

克制、恒定、档位化——这三个词共同回答「用户为什么信任一个界面」。**克制**：每个视觉量必须有存在理由，不承载信息的装饰即删除；**恒定**：几何与结构不因无关状态漂移，用户的空间记忆值得被尊重；**档位化**：设计自由度最小化，同义场景同档，差异只在语义需要处出现。设计系统的价值不在某个界面的单点惊艳，而在第一千个界面与第一个一样「像同一个产品」：可预测、可治理、可验证。六条原则是这一立场的展开：§一–§二立**治理结构**（数值从哪来、几何凭什么不动），§三–§四立**表达预算**（档位与曲线语义），§五–§六立**交互伦理**（状态如何叠加、用户意图如何被尊重）。所有落地判据均不依赖任何特定框架——任何技术栈可执行同样的自检；正文数值一律为示例值。

## 一、单一数值源＋单源镜像锁定（single source of truth＋mirror-lock）

**陈述**：一切设计数值——颜色、圆角、时长、间距、字号、不透明度，以及固定文案——只在一个地方声明；界面层只引用不复制，并用自动化测试锁定「界面层镜像 == 数值源」。

**第一性依据**：复制即分叉。两处字面量即使初始同值，演进时也必然只改其一——一致性若依赖人肉两两核对，成本随表面数平方增长且必然失守。单源＋锁定测试把「一致性」从评审时点（人工、易漏、滞后）转移到构建时点（机器、每提交、即时），治理成本降为线性：每个消费点各自对源，一致性由构造保证而非由纪律保证。引用而非复制，本质是数据流单向性——单一写者、多处读者，任何时刻全系统只有一个真相。

**落地判据**：
1. 任一视觉数值都能沿引用链走到唯一声明点；在界面层全文检索该字面量，命中数为零（声明点与锁定测试除外）。
2. 存在自动化测试按类别断言「界面层镜像值 == 数值源值」（颜色/圆角/几何边距/时长/字体至少各一组）；改源不改镜像必然测试转红。
3. 派生值（如行高）由度量公式从源推导并锁定，不手写第二份。
4. 固定文案（标题、占位提示、空态说明）同构适用：两处逐字重复即第二数值源，收敛到唯一来源。

**反例信号**：同一语义数值出现两处以上字面量（「幽灵 token」）；修一处另一处不动，靠视觉回归评审才发现；新成员不知道去哪改、就地表写；主题切换后个别界面停在旧色（构建瞬间快照式引用）。

> fts 锚点：design:3（唯一数值来源宣言）；DT:1-231；镜像测试:14/50/95/129/218（画刷/圆角/边距/时长/字体五面）；契约 #34（design-contracts.md:48）。

## 二、恒定几何（constant geometry）

**陈述**：几何不因无关因素跳变——滚动条出现/消失、按钮隐藏/显示、窗口状态迁移，都不移动无关内容的坐标；一次状态迁移一次矩形变更到位，连续迁移必须经唯一的受控动画通道。

**第一性依据**：空间记忆是界面学习的核心资产——肌肉记忆指向固定坐标，学习成本一次支付、长期复用；任何「无关状态改变无关内容位置」的机制都在强迫用户反复重付这笔成本。布局抖动的累积感知是「系统不稳」，即使每次抖动很小、单看每个动效都精美——可预测性优先于表现力。工程侧同样成立：无关状态解耦（悬浮层不占布局宽、格子固定预留、内缩静态化）让每块表面的布局只依赖自己的约束，推导局部化、验证可枚举；「迁移中途的装饰性中间态」则是对用户说谎——要么一次到位，要么走一条可中断、可重定向、终态唯一的受控通道，不存在第三种「半真半假」。

**落地判据**：
1. 滚动指示器悬浮于内容之上、不占布局宽；内容宽不随其出现/消失变化（前后截图逐像素一致）。
2. 条件性显示的元素采用固定预留格（隐藏留空、其余零漂移）或经唯一管理器的布局塌缩；不允许「隐藏了还占位挤人」。
3. 窗口/面板状态迁移一次矩形变更到位；确需连续迁移时走唯一动画通道：单一矩形权威、逐帧单调、终态唯一、可中断可重定向、减动效直达——例外必须登记，不得散布第二通道。
4. 内缩与避让量是静态值，不随悬停等瞬态重算。

**反例信号**：增删一条内容全列表横向跳动；悬停时正文文字回流重排、松手回弹；为防抖动出现常驻空槽或负边距特判；窗口收起过程闪过直角/圆角交替或残影帧。

> fts 锚点：design §五·B/§五·C（:159-174）；PlacementAnimator:65-161（受控迁移通道，Services/ 下）；契约 #23（:37，overlay 解耦）/ #16（:30，固定预留格）。

## 三、档位制而非连续值（graduated scales）

**陈述**：设计数值不连续取值——圆角、时长、字号、字重、禁用灰度各自收敛为极少数档位并附判定规则；新场景锚定既有档、不加新档；例外逐一登记。

**第一性依据**：档位数就是系统自由度。自由度越小，一致性越可机械验证（锁定测试按档断言）、评审基准越明确（「该用哪档」是查表而非拍脑袋）、组合状态越可穷举——N 维连续值的配对一致性无法验证，有限网格可以。感知侧同构：用户以相对关系（快/中/慢、轻/重、主/次）感知视觉量，同义场景同档才能建立稳定直觉；连续值制造的细微差异既不可感知又不可维护，是纯粹成本。例外是承认有限理性，不是后门：登记制让每个偏离有名字、有理由、可复审。

**落地判据**：
1. 每类数值有成文档位表＋判定规则；新场景先查表锚定，查无可用档才走例外登记。
2. 表外值零容忍：独立档、派生值逐一入册并写明理由；册与代码并存双轨即违规。
3. 档位字面量只出现在声明点，消费侧一律引用（与 §一 合流）。
4. 出现「第三档」即漂移信号：归一入档或登记例外，二选一，不许悬置。

**反例信号**：每个新功能带来自己的毫秒数/圆角/灰度，档位表越长越没人看；同义场景参数不一致，评审说不清「为什么是这个值」；例外散落代码无登记。

> fts 锚点：design §四（:119-137，圆角两档＋登记）/ §二（:63-91，时长三档锚定）/ §五（:139-145，字号档）；DT:56-58（时长三档）/ 181-195（圆角）/ 207-210（禁用两档）。

## 四、缓动按语义＋减弱动效退化（semantic easing＋reduced motion）

**陈述**：动效曲线按语义选择——进入某视觉态用减速曲线、离开用加速曲线——不按数值方向；曲线经单点实例消费；系统或用户减弱动效时，全部动效统一退化为最小表达（极短纯淡入或立即定格），时序性信息保留。

**第一性依据**：缓动方向的期待来自物理直觉——进入＝从运动到停驻，减速收尾才「落定」；离开＝从静止到离去，加速才「果断」。坐标正负是坐标系的事，与语义无关；「目标值小于起始值就是出场」这类数值判据只在单一坐标语义（透明度）下碰巧成立，位移可正可负，一换方向即错配——源项目实测教训：抬升位移被数值判据配上加速曲线，抬升加速、回落减速，与「进入减速」的宣称相反，且文档-实现不一致长期潜伏。无障碍侧，前庭功能障碍用户依赖减动效路径，这是法定约束不是加分项；统一退化口径保证「关掉」语义完整——装饰性运动消失、时序性延迟保留，信息不随动效一起被关掉。

**落地判据**：
1. 全部动效曲线经单点实例消费——改一处曲线全仓生效；直接构造曲线实例为零，锁定测试断言「同一实例」而非实现类型。
2. 缓动选择以目标态语义为判据；位移动画禁用数值方向判据；出场不慢于入场为默认，不对称例外按场景登记。
3. 减动效开关统一口径（跟随系统＋用户覆盖同键），恢复即移除覆盖；退化后全部动效不超过最短档纯淡入或直接定格，行为时序保留。
4. 动效永不作信息唯一载体：关动效后一切状态变化仍可感知。

**反例信号**：同语义两套曲线散布多处；上浮快、下沉慢这类「方向反了」的别扭感，或宣称与实现长期不一致；减动效只覆盖部分动效；用户关动效后连时序性反馈也一并丢失。

> fts 锚点：design §二（:89，缓动按语义）；DT:140-141（两条曲线值）；FadeAnimation:17-18（单点实例）；LiftAnimation:47-49（语义判据修正，源码注释在案）；契约 #41（:55，运行语义）。

## 五、分层叠加状态＋悬停双轨（layered states＋dual-track hover）

**陈述**：状态视觉用独立图层交叉淡入表达——不换色、不重排；悬停反馈按控件类型学分轨，按压收敛为少数范式，键盘焦点最小化；阴影与特效隔离在不承载文字的图层。

**第一性依据**：状态是正交维度不是替换关系——一个元素可同时「悬停＋选中＋禁用」；换色式状态把正交维度压进单一视觉属性，组合即互相覆盖，图层化让每个维度有独立生命周期，组合是自然结果。瞬态反馈存在承诺等级：悬停是「可能操作」的低承诺信号，按压是「正在操作」，选中是「已操作」——同一强度表达会稀释反馈梯度；悬停分轨（复合元素层淡入/轻表面属性瞬切/密集内容仅描边）本质是按承诺等级分配表达预算，密集处只动描边是信息密度与反馈强度的折中。渲染侧存在字节级代价：特效管道会把子树渲染进中间位图并关闭亚像素文字抗锯齿（正文发糊），逐元素实例化拖垮虚拟化——特效隔离在无文字图层＋共享冻结单实例，不是风格偏好而是渲染管线的物理约束。

**落地判据**：
1. 任一控件的状态视觉＝各图层各司其职交叉淡入；「换底色＋重排」组合零出现。
2. 悬停三轨按类型学落位：复合图标元素层淡入、轻表面控件属性瞬切、密集内容控件仅描边——无第四种。
3. 按压收敛为少数范式（换色/缩放/透明度），轻量选择类无按压态；键盘焦点仅文本输入可见可辨，其余控件不参与焦点链。
4. 阴影/模糊等特效只在无文字图层；特效对象全仓共享冻结单实例。

**反例信号**：悬停整卡换底＋文字位移，列表像「跳」了一下；每个组件自创一种悬停；正文发糊、长列表滚动掉帧；满屏焦点框，或键盘用户完全无焦点可见。

> fts 锚点：design §三（:93-117，类型学×五态）；M:108-143（层淡入）＋ SW:271-274（按压透明度范式）；M:200-201（焦点描边）；QuickLaunch:1178（按压缩放）。

## 六、克制与真实可达＋意图事务（restraint＆real reachability＋intent transaction）

**陈述**：动效可中断、不阻断命中测试、永不作信息唯一载体；不可用性不用禁用态表达（入口保持可命中＋守卫与徽章告知原因）；悬停只预览、激活属点击——确需悬停触发激活级动作时，用意图事务（布防→驻留到期→重验指针仍在→才提交）防扫边误触；关键路径必须经真实输入验证。

**第一性依据**：用户时间是主权——等待动画播完才能操作等于系统抢走控制权；可中断（新状态先复位终值再挂新动画）把「最新意图」置于「进行中的表达」之上。可达性有两层：逻辑可达（合成事件能触发）≠ 真实可达（真实输入管线——输入法组合、系统消息路径、无障碍驱动——也能触发）；「测试绿了用户点不到」是最阴险的缺陷，因为一切证据都说没问题。悬停没有承诺语义：指针扫过是最低意图信号，点击才是承诺；用低意图信号触发高后果动作必然成片误触——意图事务用极短驻留的时间成本换意图确认，验证的是「指针还在」即意图仍成立，比再加一层防抖更诚实。禁用态元素不可命中：用禁用表达「不可用」会让点击穿透成误触（点了没反应或点到下层）；入口守卫＋视觉徽章让用户「看得见、点得到、被告知为什么不行」——灰度只是视觉表达，不是交互屏障。

**落地判据**：
1. 任何动画可被新状态中断且先复位终值；动效层不参与命中测试。
2. 不可用入口保持可命中：点击给出解释（提示/徽章），不静默吞掉、不穿透下层；禁用档位只管视觉灰度。
3. 悬停触发的激活级动作全部走意图事务；快速扫过一排条目零误触。
4. 关键指针路径有真实消息驱动的验证用例（非仅合成事件）；动效关闭时全部状态信息仍完整可感知。

**反例信号**：必须等动画播完才能操作，快速来回操作后界面错乱；扫过一排条目误触发成片；测试全绿但真机点不到；点「灰掉」的元素穿透误触下层；关动效后某些状态变化彻底不可见。

> fts 锚点：契约 #13（:27，真实消息守卫）/ #62（:74，悬停驻留提示先例）；DT:86（意图驻留窗，示例值 60ms）。
