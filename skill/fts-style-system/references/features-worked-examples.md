> **来源**：fts 基线 1.72.0（commit `bba9b4e`）实证提炼。**日期与行数预算**：2026-11-12 重建；≤400 行（现 111 行）。按需精读，不必先读。

## 例一：chip 过滤轨（窄横轨多选一过滤＋轻量归属）

**结构**：头行与列表之间的固定高行（示例 36 结构常量，非 token）；N 个槽 chip＋轨首「全部」伪 chip，等分容器恒等分；chip＝容器（1px 描边＋小圆角 6 派生登记）＋悬停层＋激活层＋拖放层＋落点指示环四层叠加＋文字/就地编辑器互斥件；轨整体显隐由**单一布尔**驱动。

**关键约束**：
- 过滤谓词**单点**（搜索与子分组共用一处，**搜索压倒子分组**：搜索激活时 chip 过滤冻结让位、退出自动恢复）；过滤态继承既有口径（进入清空选择、禁拖放与全选〔拖放落点按过滤视图计算会错位〕、抑制自动收起、Esc/切分类/模式切换退出）。
- 「全部」伪 chip **无槽身份**（不参与槽序/改名/归属/落点、无拖放事件）；模板选择器按条目**实际类型**二分分派（禁伪槽哨兵值、禁散布类型守卫）；「全部」复用同一样式族（数据侧同名属性命中同一触发器——样式级鸭子类型）。
- 悬停过滤守卫链五条件（窗口关闭中/改名激活/**拖拽在途**〔拖卡滑过 chip 触发的进入是假信号〕/外部拖放轨可见/搜索激活）；**不做防抖**（过滤是轻量纯视觉操作，防抖制造迟滞）。
- **落点指示环三态语法**：紫（强调色）＝当前有效落点；灰（复用次级文字色）＝具备能力但非有效（未设默认时兜底显示序首槽恒灰）；无环＝永不具备能力。轨可见时**恰一枚环**；环与选中态是两套语言禁止互相借用。
- 悬停 vs 点击双轨（实验开关）：点击轨模式下**过滤状态机与消费点零改动**，只改「事件→动作」映射（悬停退役为纯视觉、裸单击 toggle、Ctrl+单击设落点、单击「全部」进全量态）——悬停误触的根治是**换手势承载**不是加防抖。
- Ctrl+单击＝设收集落点（会话态、不持久化、每分类独立、单击即换无取消手势）。
- 拖放：撤离保持窗（120ms，版本号＋断言时刻＋帧循环重验；**从未断言过的撤离立即清**）消灭隐-现脉冲；插入指示线＝2px 强调色圆角横线覆盖层不参与命中、落点槽位在条目竖直中线翻转＋相邻翻转迟滞 ±3、同位隐藏。
- 共享改名会话：双击进入（判定在按下连击计数；单击动作在释放；两处排除编辑器内点击）；会话机器收敛为**单一会话类**（被改对象构造注入，新增改名位＝登记一个实例）；Enter/Esc/失焦/点外/切面板五出口统一；**输入法组合期 Enter/Esc 旁路、组合期不限长**（组合终结后统一收敛归一）。

**可迁移要点**：①「过滤＝单点谓词＋压倒序」比每过滤源一套状态机稳；②伪元素用类型分派而非哨兵值；③标记系统让「位置与颜色同时承载信息」；④悬停误触治理＝结构消灭（改点击）＋实验开关灰度双轨，不动状态机。

## 例二：停靠面板贴边 peek（窗口级动画）

**结构**：三态＝展开/收起把手（面板状态机二态）＋贴边 peek（`Idle→Armed→Peek` 一次性武装，会话级不持久化）；peek 态＝整窗**同尺寸纯平移**（绝大部分出屏、屏内仅留 16px 把手，token：dimension.size.peek-handle-width）；把手＝窗壳底＋缘描边＋居中 grip 的独立命中层（窗口级命中面非钮）；收缩/展开经唯一放置动画服务（逐帧插值＋系统放置调用纯平移帧）。

**关键约束**：
- **三值同值**：把手视觉宽＝命中宽＝屏内保留宽（16）——不透明窗无透明命中区，解耦即露出内容切边。
- **双层状态机**：相位层（纯逻辑零界面依赖可单测）＋动画层（独立放置动画服务承载进行态）；动画期间**窗口矩形权威归动画服务**，界面属性账本只在完成/取消一次收口。
- 提交时机复用既有收起节奏（指针离开→驻留计时 250ms〔慢档 token 同源〕→到期 tick 内若已武装且抑制不成立走贴边收缩）；收起抑制谓词与面板收起复用同一套（指针在内/拖拽/编辑中/驻留锁定）。
- **60ms 悬停意图事务**：布防→到期重验「仍处 Peek 且系统指针仍在窗口矩形内」才提交展开；防扫边误触，不加防抖层。
- **解除出口四条共用一个记账单点**（把手事务提交/全局热键/显示器变化立即展开防丢窗/外部拖放揭示）；Peek 态武装切换＝防御 no-op；与「保持展开」**互斥组**（后激活者胜；释放＝条件解除，仅当当前持有者恰为该意图才清空）。
- **反向救援禁原点重放**：收缩途中指针追入→捕获当前实时进度为新起点、时长按剩余距离比例重映射封顶满时长；展开途中不中断。迁移原子性铁律与例外通道五条款见 [motion.md](motion.md) §五。
- 恢复兜底：不持久化离屏态；持久化只存归一量＋工作区钳制（显示器变更后不可能丢屏外）。

**可移植要点**：①窗口级动画「单一权威＋单调＋终态唯一」让原子迁移契约可开例外通道而不失序；②可注入时钟（生产渲染帧/测试手动推帧）让窗口动画可逐帧断言；③Web 等价＝`transform: translateX()` 合成器通道＋`elementFromPoint` 重验＋单字段互斥。

## 例三：容器变换弹层（container transform overlay）

**结构**：同一内容双宿主（角落缩略钮↔全幅放大层）；放大层三层＝遮罩纱（半透明压暗）＋放大卡容器（**布局层与渲染变换分离**：布局树一次到位，飞行由代码构造的缩放＋平移渲染变换组驱动；容器再拆阴影层＋内容面）＋源缩略图；内容三元素（标题/主内容/脚注）**布局恒占位、透明度基值 0**。

**关键约束**：
- **四变换同帧启动＝矩形插值成为结构性质**：缩放两轴（ScaleX≠ScaleY 承载方→矩形非等比形变）＋平移两轴，同 duration 同缓动同帧——对称往返不靠「两套动画凑巧对称」。
- **文字 60% 进度后段浮现**（fade-through 迟到进场；示例入场 450ms、文字 270ms 起 180ms 淡入）——落位时可读、从不随容器缩放呈现。
- **收回＝三段线性＋交叉淡化**（示例收回 250ms）：文字先隐 90ms；缩略图回显起点＝收回曲线**反解 95% 回程**（≈0.722×时长→180ms，容器已≈落位才回显防中段双影）；交接段（差值声明＝收回−回显起点）两元素**等斜率线性交叉**，合成存在感恒≈1（无台阶/空窗/双影）；遮罩与容器同曲线同时长收回（防末段骤曝）。
- **独立时长组契约化登记**：整组时长/曲线不并入三档、不加第四档、不被组外借用；数值**外部文献出处**（入场曲线＝iOS 转场测量近似、收回曲线＝系统默认缓动、时长与文字编排＝Material container transform/fade-through）＋「先文献定初值、再实测收敛、终值回写 token」。
- **几何测量剥自身渲染变换**：坐标变换 API 会穿过容器自身渲染变换，飞行中直接测量被自身动画污染（放大误差）——源矩形＝含变换原点减平移分量法；不缓存测量结果。
- 生命周期守卫：代数计数（每次开/关自增，掉队完成回调作废）；「卡片可见度自持」不挂在遮罩可见性上（父子相乘）；父子透明度同帧同曲线＝「兄弟」不相乘；一切出场 From 显式取**当下实测值**（禁自基值起跳）。
- 退化路径：减动效＝定格全显终态（不用长淡出替代）；测量失败＝容器快照当下值定基＋整段线性淡出，终态与正常路径逐值一致；扫码面恒白是**主题不变量**（物理约束），深色用主题阴影高程「岛」式抬出。

**可移植要点**：①大位移/形变弹层走 container transform（含框飞行）而不是纯淡入＋缩放两截；②「防双影/无台阶交接」靠可推导的时序编排常量不是目测调参；③Web＝FLIP/View Transitions API 直译（`view-transition-name` 同名快照变形＋`::view-transition-group()` 覆写时长曲线）。

## 例四：实验开关体系（默认关＋一次性迁移）

**结构**：偏好字段（bool 默认 false 或枚举默认 Off；旧文件缺字段回落默认）→ `ApplyPreferences` 唯一管线即时生效＋**窗口构造段镜像下发**（启动不走 ApplyPreferences，漏构造段＝重启后开关失效）→ 设置窗「实验性」节逐项开关/下拉。

**关键约束**：
- **默认值翻转走一次性版本化迁移**：偏好带迁移版本戳（默认 0）；启动装载后、主窗构造前单点判定——戳<目标版→目标键置新默认＋写戳＋经唯一存储管线原子落盘；戳≥目标版原引用返回零写盘。四性质：门控（已迁移者永不重放）/幂等（重跑零重写）/IO 自愈（写失败采纳带戳内存基准续跑，下次重放收敛）/一次性语义（迁移后用户显式选择永不复翻）；「自动落盘的显式关闭也会被翻开」的歧义代价须公示。
- **退役＝删除而非恒真保留**：偏好字段/管线/设置 UI 全链移除，旧 JSON 残留键按**未知成员忽略**（不迁移不回落任何语义）；**删除的开关不进迁移**（无状态可变换）；实验节空置不删节。
- 开关判断收在**单一层**（调度器/载荷构造层/手势路由层），UI 事件层与管线零开关感知；开关即点即生效＋立即持久化（无保存按钮/确认弹窗），全部经唯一应用管线（禁平行保存路径）。
- 节头＝**判据式文案**不罗列默认值快照（默认值写进节头＝与文档双写漂移）；默认值/为什么实验进**行悬停说明**（挂点统一单处）；三类红线信息（隐私与数据外发/默认值变化/不可逆操作）**常可见**不收进悬停。
- 构造回显＝直赋＋同步段早退（非双向绑定——绑定回路在装载期触发变更事件，回显守卫失效或保存竞态）；自绘开关悬停仅描边、状态瞬切无动画、禁用复用全局 0.4 档。
- 毕业判据成文（示例「连续两个版本无语义修订且无报障」）。

**可移植要点**：①「实验性默认关→默认开」必须配一次性迁移；②「启动装载后、主窗构造前」是迁移唯一时点；③Web/localStorage 等价＝单键快照＋整数版本戳＋单函数门控＋原子写；增量式存储（只存显式设置过的键）天然免迁移，快照式则公示翻转代价。

## 例五：Markdown 阅读视图（排版层）

**结构**：记录表面获得只读渲染视图（源文仍是唯一事实源）；「阅读/编辑」分段切换（单选语义组，选中＝活动层底＋半粗）只在开关开启且表面激活时可见；渲染管线两段式＝解析映射器（源文→纯文档模型，零界面依赖）＋渲染器（模型→流文档呈现）。

**关键约束**：
- 排版数值唯一来源 token：标题阶梯 H1–H3 显式（示例 20/17/15），**H4–H6＝正文字号＋半粗权重**（不设第二份正文字号）；块距/代码内边距/引用条宽各一枚。
- **颜色零新增**：正文/引用＝主文字、次级说明＝次文字、链接＝强调色（下划线）、代码底＝悬停面、描边＝通用描边——全部复用主题语义键活引用，主题切换即时生效；「新增一个渲染面」不该新增任何颜色。
- 代码字体是**独立功能来源**（等宽系统必装链＋回退），不随界面字体变化；阅读档**不设显式行高**（沿用字体自然行距，与卡片区显式推导行高不同路）。
- 只读派生：阅读态从不回写（保存/合并管线不复制第二份）；切入阅读态交还宿主焦点（否则 Esc 语义被阅读面劫持）；链接白名单＝仅 http/https 绝对 URL 可点击（交系统默认浏览器，打开失败静默放弃）；语法子集刻意收窄（表格/脚注/原始 HTML 不解析，按**源文切片**降级呈现——不丢内容不半解析）；软换行按阅读惯例渲染为换行；图片不加载（离线）。
- 双态切换无动画（状态语言）；开关关闭＝零占位（逐像素等于现状）。

**可移植要点**：①富文本排版层数值全进 token、颜色全复用语义键；②「档位不够用时用权重区分而不是加字号档」；③功能性字体（代码/图标）与界面字体分离声明；④渲染纯函数 `text → DOM` 不回写不复制状态。

## 例六：设置窗双栏 IA

**结构**：三行骨架＝标题栏（无边框窗拖拽区）／双栏主体（左导航列固定宽＋右内容列自适应）／页脚（滚动区外常驻）。左导航＝**原生单选钮组**（自带选中项语义与可访问角色，不手写互斥）；选中态复用导航轨语言（活动层底＋强调色左指示条＋半粗）；右内容页＝**常驻面板组只翻可见性**（页面永不重建，切换零状态丢失）；全部页共享**单一滚动视口**（overlay 滚动条）。

**关键约束**：
- 单一共享视口两个论据：①宽度稳定性（各页高度不同，占位滚动条的出现/消失会让各页内容宽度跳变；overlay 悬浮其上则逐像素相等）；②名字空间唯一性（每页各自视口要求独立命名挂点，破坏按名寻址与辅助功能直达）。
- 内容列对齐＝拉伸填充＋最大宽钳制（受钳的拉伸自动居中）；**禁止水平居中对齐**（列宽随最宽页收窄，页页不等宽）。
- 切页处理器单点：按名寻址逐页翻可见性→共享视口回页首（滚动偏移不跨页残留）→入场纯透明度淡入（167ms 中档；不用主界面导航的位移显现——场景不同不搬编排：平级翻页无「内容从轨下拉出」语义）。
- 键盘循环确定性：方向键在**预览（隧道）阶段消费**并压掉单选钮原生方向导航（原生一次跳多步不可预测）；循环用取模；Home/End 特判；目标项「选中＋聚焦」双置。
- 构造期陷阱：声明期解析中途首项选中事件已触发而后续页未解析——初始可见性声明期定死＋寻址判空跳过（不靠事件回放）。
- 页脚＝非导航：物理在导航组之外、无组名、非单选钮——永不参与互斥永不被选中（「退出」不能是导航态）；窗体几何属冻结几何唯一声明点（结构不为内容让步），交互缩放上限走系统消息轨道强制（关联反例 A19）。

**可移植要点**：①「常驻只翻可见性」＝Web 路由切换不卸载面板（keep-alive 策略，保留表单状态与滚动位置）；②键盘＝roving tabindex＋环回箭头＋`preventDefault()`（等价隧道消费）；③切页回页首＝显式 `scrollTo(0,0)` 并关闭滚动恢复。

## 例七：AI 识图命名（后台管线＋交付层参数化）

**结构**：三段式——①调度器（开关判断单点、全局串行队列并发＝1、会话级一次性尝试标记不重试、无 Key＝零请求＋每轮排空状态条恰一次、存量补扫）；②命名落板（元数据字段、不进撤销栈、保存失败还原）；③交付层参数化（拖出载荷构造核心的参数：有名且外部交付开启→临时副本以清洗名交付、受管本体绝不动、同批名唯一化、拖放返回后单点清理；无名/关→现状）。

**关键约束**：
- 开关默认关；判断唯一在调度器（入库管线与 UI 事件层零感知）。
- 命名展示挂**命中层的祖先**（直接挂缩略图因命中层拦截永不触发悬停提示）；null 自动不显示。
- 图片编码必经受限解码＋缩略（长边上限）——安全边界与容量预算复用既有闸。
- 剪贴板路径**不连坐**（临时文件生命周期无法绑定剪贴板会话——技术根因登记，不为对称性硬造清理钩子）。
- 设置卡隐私披露逐字锁定（「发送至 X」锚点句必在可见文案，不收进悬停）。

**可迁移要点**：①后台 AI 管线＝调度器单点开关＋串行队列＋会话级不重试三件套；②「交付形态变化」参数化在载荷构造核心（一处参数两态形状），UI 入口零感知；③临时文件交付必须记账＋单一清理点＋受管本体绝不动；④隐私披露是 AI 功能的 UI 必备件，逐字锁定防漂移。（本例锚点溯源见 [fts-provenance.md](fts-provenance.md) §七。）

## 通用总结（七例共性）

1. **状态机/谓词单点**：每例都有一处唯一判定点（过滤谓词/矩形权威/开关判断/切页寻址），消费面全部引用不复制。
2. **既有范式优先**：新特性复用既有视觉语言（chip 沿分类标签、环沿默认标记、阴影层沿卡片三层），不为新功能另起一套。
3. **实验开关灰度**：行为分歧大的交互（悬停 vs 点击）用偏好开关双轨，判断收在路由层。
4. **数值全部进 token 或登记例外**：七例零新增散布字面量；行为计时器豁免成文登记。
