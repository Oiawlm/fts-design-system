# layout-paradigms：布局范式六式（表面类）

> **定位**：新项目第 4 步「组件范式选型」——设计体系验证过的六个表面类布局范式，每式给结构、关键约束与可移植要点；特性级动态范式（chip 轨/贴边 peek/容器变换/实验开关/阅读视图/设置 IA）见 [features-worked-examples.md](features-worked-examples.md)。
> **来源**：源仓 docs/patterns/ 表面六篇（card/tile/grid/scrollbar/dialog/empty-state）提炼；fts 基线 1.72.0（commit `bba9b4e`）。数值均为**示例值**；fts 锚点见 [fts-provenance.md](fts-provenance.md)。
> **日期与行数预算**：2026-11-12 重建；≤400 行（现 103 行）。按需精读，不必先读。

## 一、分层状态卡片（任何「带阴影的可悬浮面」通用）

**结构**（自外向内三层外壳＋内容）：

```
根容器（Grid）      —— 外距与悬停上浮（渲染位移）；自身无任何效果
 ├ 阴影层（Border） —— 与卡片同形状的不透明底＋共享冻结投影；不承载内容、不参与命中
 └ 内容面（Border） —— 不透明卡片底＋1px 描边＋圆角；禁携带效果
    ├ 五个独立状态层：悬停填充/悬停描边/选中填充/选中描边/编辑环（各自透明度归零为基态、交叉淡入、不参与命中）
    ├ 内容网格两行：备注行（空则塌缩）＋内容视觉层（图片态全宽缩略图｜文字态限高省略）
    ├ 对分手势分区命中层：两列等分透明网格（区域＝元素身份：左半编辑与拖拽/右半复制；右键选择全卡面统一）
    └ 右上操作格：绝对两列×按钮行（正方格＋独立间隔行；行优先序后新增向下占格）
```

**关键约束**：
- Effect 只在阴影层（带 Effect 的元素把整子树渲染进中间位图并关闭亚像素渲染——正文发糊主因）；内容面不透明（否则阴影透出）。
- **操作格固定预留**：格子与按钮同宽高、隐藏留空、其余零漂移；禁等分面板/换行面板做按钮区（不支持「隐藏留空」语义；例外：等分恒列数本身是需求时恰是正解）。
- **文字避让是静态派生公式**：正文排他内缩＝列数×列宽＋间隙（示例 2×30＋4＝64），唯一来源派生资源，不得写死第二份；只作用于文字态；不随悬停变化。
- **就地编辑器同度量**：与显示态同字体/行高/限高，编辑期同格盖写、显示态不塌缩，卡片高度恒定；编辑环声明在选中环之后（叠加时在上）。
- 列表宿主与分区边界：边界宿主在列表项容器模板内、由「该项是否分区边界」数据标记唯一驱动（置顶分区四态：无/实线/虚线/强调条，经偏好槽位换装，「无」＝零高零描边；分组边界恒可见独立线）；禁代码后置逐容器设状态、哨兵数据项、第二套判定。
- 悬停上浮＝渲染位移 −1px（瓦片 −2px 对仗），按语义选缓动。

**可移植要点**：CSS 中投影可直挂卡片（浏览器无中间位图问题），但**状态层叠加照搬**——伪元素/绝对定位子层＋transition 交叉淡入；悬停上浮 `transform: translateY(-1px)`（勿用 top/margin）；手势分区＝两个绝对定位半区元素（「区域＝元素身份」标记判定，抗 DPI 抗重构）；操作格＝CSS Grid `repeat(2, 30px)`＋`visibility: hidden`。

## 二、快捷操作瓦片（action tile）

**结构**：瓦片根（表面档圆角＋2px 透明描边——描边常在，失败/选中/拖放只换描边色不加宽；根上挂渲染变换组）＋两行内容（图标槽 48×48：应用类「占位字形＋图片提取链」两态、链接类「地球字形＋图片」两态；图标槽同时是启动手势分区：单击启动、拖拽仅从此区发起；名称带底部整带：单击聚焦、双击就地改名、多选时单击改选中）＋两枚叠加小件（警告角标 16×16 胶囊；右上勾选钮 30 命中/16 环，可见性＝悬停∨选中∨键盘聚焦三信号或）＋右键菜单（按态禁用——打开瞬间按当前下标置灰，不预先隐藏）。

**微交互五族**（全部只动渲染变换或不透明度）：悬停上浮 −2px/167ms；按压缩放 0.96/83ms；确认脉冲 1→1.06→1（峰在中点）/250ms；失败闪 1↔0.2 两闪后**常显**危险色描边＋半透明图标＋角标（闪烁是转向常显态的过渡，动效永不作信息唯一载体）；落位 0.8→1 缩放＋淡入（仅**真正新增项**触发——排序/图标回填/改名/撤销恢复不播）。守卫：启动重入门闩（同窗第二击不重复派发）。

**几何**：瓦片宽 84 是**下限**（实际宽由网格摊分）、高 100、沟道 8、节距 92；**视口顶/底内衬 8** 吸收渲染变换溢出（悬停上浮/脉冲越过视口缘会被裁剪，首/末行无沟道缓冲——内衬随内容滚动）。名称带限高两行（32）＋省略号（防行数变化牵动网格行高）。

## 三、自算拉伸填充网格（无量化死区）

**结构**：全部几何出自**单一计算源**（纯函数模块），承载面板测量/排列两阶段现算自排版：

- 列数公式：`n = clamp( floor((视口宽 + 沟道) / 节距), 列数下限, 列数上限 )`（示例 3–6）。
- 瓦片宽公式（余宽全摊）：`w = (视口宽 − 沟道×(n−1)) / n`——行满排总宽**恒等于视口**、零死区；域内构造保证 w ≥ 下限。
- 禁止：①「公式算固定宽＋布局面板再量化」双口径；②滚动回调回写自身宽度（自引用反馈回路——缩放时几何震荡）；③居中网格（行满排设计下居中即制造死区）；④瓦片自带外距（沟道只由排版承载）。
- **列数策略扩展点**：默认自适应＝公式；固定档与视口无关恒等于档值、宽仍摊分（显式用户选择允许压到下限以下）；策略经依赖属性下发，赋值即失效重测。
- 网格本体纯静态排版（列数/宽度变化直接进下一次布局，不做几何过渡）；视口 0 与非有限输入走列数下限兜底。

**可移植要点**：CSS `grid-template-columns: repeat(auto-fill, minmax(84px, 1fr))` 原生即「钳制列数＋余宽全摊」（浏览器布局器＝天然单源）；**摊分恒等式是验收断言**：`n×w+(n−1)×gutter === viewportWidth` 可写成布局测试。

## 四、Overlay 瘦滚动条（滚动条永不占布局宽）

**结构**：滚动视口模板为**单格叠加**——内容台与垂直/水平滚动条同格叠放，条带贴右/底缘悬浮、不占布局列；条带最小宽/高压到 0（挤掉系统滚动条尺寸下限——那是「不占宽」失败的技术根因，实测下限约 17 DIP）；`Auto` 语义保留（需要时才出现，不引入自动隐藏定时器）。三命名部件齐全（透明轨道按钮/瘦拇指/水平同理）——键盘滚动与翻页语义的生命线。

**瘦拇指＋悬停展宽层**：基宽 4、最小高 24、圆角 2（线状派生＝宽一半）；悬停不改基宽——拇指内叠加宽 6 悬停层交叉淡入（167ms），「展宽＋换色」一步完成，几何与颜色解耦。条带宽 8 整体落在宿主内容右缘留白带（12）内——**与内容零遮挡是几何前提**，新宿主接入前先核对右缘留白。

**两宿主挂接（同构）**：列表宿主＝列表控件资源作用域内 keyed 隐式样式（**不做全局隐式样式**——不波及无关滚动面）；文本输入宿主＝从基样式**派生**只重写内容宿主模板（画刷/圆角/聚焦环单一来源不变；打字途中滚动条出现/消失不改变排版宽）。

**两轮布局恢复**（切换/过滤后恢复滚动位置）：①按上下文保存偏移（粒度＝内容分组）；②换绑后**先强制完成一轮布局**（建立真实可滚动高度——换绑瞬间旧高度是陈旧值）→ 按保存值钳制滚动 → **再完成一轮布局**，两轮都发生在内容淡入之前（首帧直接落最终偏移，无「先顶 0 再跳」双帧闪现）；③版本号取代（在途异步恢复被新恢复取代）；④≤0.5px 幂等短路。

**可移植要点**：Web `scrollbar-width: thin`＋`scrollbar-color` 保底（悬停展宽不可得则接受「换色不展宽」，**别为展宽改自绘浮层**——失去原生滚动手感与无障碍语义）；两轮恢复＝`scrollTo` 前先 await 一帧布局，首帧前恢复（容器仍隐藏时完成滚动再显形）。

## 五、单壳对话框

**结构**：全部小对话框共用**一个壳样式**——不透明对话框表面色（独立语义键，与卡片表面分立）＋1px 描边＋表面档圆角＋统一内边距 24；圆角与阴影**唯一来源＝窗口系统层**（系统级圆角偏好＋系统阴影随圆角自动生效），内容壳同值自裁剪；壳自身零手工效果、零入场动画（对话框的价值是即刻可交互）。

**关键约束**：禁止「透明背景＋margin 挤圆角＋手工投影」假圆角三件套；禁止弹窗套材质/半透明；**直角回退兜底**——系统圆角设置失败（远程会话/旧系统）时壳圆角**归零**回退完整直角＋边框（不是保留圆角祈祷，也不是补第二套装饰）；深浅标题随主题同步（不出现浅标题配深内容）。

**可移植要点**：Web 是降维场景——`<dialog>` 或壳组件（表面色＋1px 描边＋8px 圆角＋24px 内边距）就是全部；「一个壳多窗复用」＝一个壳组件多对话框复用；降级思维移植：`forced-colors` 模式退到边框完整的直角卡；`color-scheme` 随主题切换让原生部件跟随。

## 六、空状态构图（信息层命中穿透）

**结构**：居中纵排三件套——图标（字形尺寸族，次级色）＋标题（正文档＋半粗＋主文字色）＋副文案（次级档、可换行）；空态**不占布局格**（与内容同格叠加、互斥可见性），出现/消失不牵动周围结构。

**关键约束**：
- **命中穿透**：信息性空态一律关闭命中测试（点击/拖放穿透回底下列表/输入面）；CTA 宿主除外。
- **无 CTA 默认**：按钮只属于「进入路径＝显式动作」的空态（CTA 判定是产品决策：先回答「这个空的进入路径是什么」）；对拖入/输入/等待型空态放按钮是错误引导。
- **文案二维矩阵单点**：标题/副文案由 (内容分类, 是否默认接收) 查表穷尽派生，无兜底臂（新增分类漏映射＝编译期失败而非运行期空白）；同一语义散写各宿主＝改一处漏三处。
- **唯一求值点**：一个函数从当前状态一次算出全部空态宿主的可见性与文案并应用；全部触发路径（表面切换/集合增删/默认接收迁移/搜索进出/过滤）汇聚调用它；求「求值点唯一」不求「调用次数最少」。订阅**视图侧**集合事件（源事件里同步求值会读到未消化变化的过期视图）；后台线程事件统一封送回 UI 线程。
- 空态零动效（越安静越好；空→非空即时切换）。

**可移植要点**：命中穿透＝`pointer-events: none`；文案矩阵＝穷尽 switch/对象表＋类型系统（新分类编译期报错）；唯一求值点＝「单一 derive 函数＋全部 mutation 路径调用」（等价 store selector）。

## 选型速查

| 需求 | 用哪式 |
|---|---|
| 垂直滚动密集内容列表（每条 2–4 个轻量操作） | 一（分层状态卡片） |
| 等尺寸动作入口网格（图标为主、单击即触发） | 二（瓦片）＋三（网格） |
| 任何可滚列表/大篇幅文本输入面 | 四（overlay 滚动条） |
| 短生命周期模态对话（输入一行/选一项/确认一次） | 五（单壳对话框） |
| 「集合可能为空」的任何表面 | 六（空状态） |
| 横向流/异构尺寸/无限滚动大数据 | 均不适用（另选宿主） |

## 验收自查

- ☐ 三层外壳三层职责互斥（效果只进阴影层、文字只进内容面）；共享冻结单实例。
- ☐ 状态层交叉淡入，不换底不重排；操作格固定预留隐藏留空；避让内缩静态派生唯一来源。
- ☐ 瓦片微交互只动渲染变换；失败态常显信息独立在场；落位仅真正新增。
- ☐ 网格单一几何源；摊分恒等式成立；无自引用回写。
- ☐ 滚动条 overlay 不占布局宽；三部件齐全；两轮布局恢复无闪跳。
- ☐ 对话框一壳复用；系统圆角唯一来源；直角回退完整。
- ☐ 空态命中穿透；文案矩阵穷尽单点；唯一求值点覆盖全部路径并集。
