# motion：动效与交互状态规范

> **定位**：新项目第 5 步「动效档位映射」与交互状态选型——三档×场景全景、两条缓动**按语义选**、可中断实现、意图事务、交互状态类型学（hover 双轨/pressed 三范式/禁用两档/Focus 矩阵/分层叠加）、窗口级例外通道与减动效统一退化；数值均为**示例值**（括注 token 路径）。
> **来源**：源仓 docs/motion.md＋docs/interaction-states.md 提炼；fts 基线 1.72.0（commit `bba9b4e`；三档示例值出自 Win11 Fluent 官方时长表）。fts 锚点见 [fts-provenance.md](fts-provenance.md)。
> **日期与行数预算**：2026-11-12 重建；≤400 行（现 133 行）。按需精读，不必先读。

## 一、三档时长×场景全景

| 档 | 示例值 | 典型场景 | token 路径 |
|---|---|---|---|
| 快 | 83ms | 按压反馈、贴边把手登场淡入、减动效纯淡出 | motion.duration.fast |
| 中 | 167ms | 悬停反馈、面板展开内容入场、贴边收起出场（加速曲线） | motion.duration.normal |
| 慢 | 250ms | 标准控件动画、启动确认脉冲、新条目落位、贴边展开入场（减速曲线） | motion.duration.slow |

**场景时长登记表**（新场景从三档起步，不为凑值引入新档；场景值＝三档别名或登记的原始值）：

| 场景 | 示例值 | 性质 |
|---|---|---|
| 面板展开内容入场 / 悬停反馈 / 按压反馈 / 启动确认 / 新条目落位 | 167/167/83/250/250 | 档位别名 |
| 面板切换 | 140 | 场景原始值（轻过渡） |
| 面板收起出场 | 200 | 场景原始值（不对称登记例外，§二） |
| 分类揭示 / 显隐淡入淡出 / 删除反馈 / 拖放撤离保持窗 | 120 | 场景原始值 |
| 启动后排队收起延迟 | 250 | 慢档同源（时序性延迟，减动效保留） |
| 启动重入门闩 | 500 | 编排门闩（同窗第二击不重复派发，非视觉档） |
| 交错步进 | 40 | 节奏值（与封顶规则绑定，§三） |

- **行为计时器豁免**：意图窗 60ms、chip 驻留 300ms、状态保持 4s 等是**时序编排值非视觉档**，不设视觉 token——豁免必须成文登记，禁止静默字面量；**同值异义禁止共用**（示例：把手意图窗与面板展开意图窗同 60ms 但语义不同，各自登记）。
- **独立时长组是极少数契约化例外**：容器变换弹层一组专用（示例八枚 450/250/270/180/90/150/180/70＋两条组内专用曲线，数值源为外部规范考据——iOS 转场测量近似＋系统默认曲线＋Material container transform/fade-through 编排；详见 [features-worked-examples.md](features-worked-examples.md) 例三）。为何例外：多动画同帧编排，三档的「单值单曲线」模型装不下它的编排包络；如何登记：整组契约化＋外部数值依据；边界：不进三档、不被组外场景借用，新增独立组必须给出同等依据。

## 二、两条缓动——按语义选、不按数值方向

| 语义 | 示例曲线 | 观感 | token 路径 |
|---|---|---|---|
| 进入某视觉态（淡入/抬升/入场/展开） | cubic-bezier(0,0,0,1)（减速） | 快出缓停 | motion.easing.enter |
| 离开某视觉态（淡出/回落/出场/收缩） | cubic-bezier(1,0,1,1)（加速） | 缓出快收 | motion.easing.exit |
| 减弱动效 | linear 或直接定格 | — | —（§六） |

- **选择规则＝语义**：「目的地是进入视觉态还是离开视觉态」。「`to < from` 用加速」只是透明度语义下恰好成立的判据（淡出数值必变小）；位移抬升（如 0→−1px）数值同样变小，套用即错配（源项目曾实测与宣称相反并修正为按目标态判别：`to == 抬升值 ? enter : exit`）。位移动画禁用数值判据。
- **缓动单点实例**：全部动效经统一缓动工厂/单一实例消费（桌面端共享缓动对象；Web 端 CSS 变量直用），禁止散布 new 曲线实例；专用曲线经同一工厂的 token 参数指定。锁定测试断言「同一实例」而非实现类型。
- **不对称原则**：出场快于入场；登记例外按场景标注不泛化（示例：面板展开 167ms/收起 200ms——收起节奏的场景登记值）。

## 三、编排（可中断、入场事件、意图事务）

**可中断动画四要点**（全部动效的默认实现纪律）：

1. **新状态先复位终值**：先清挂起动画、属性写定新终值、再挂新动画——动画永不承载终值语义，用户不必等动画播完。
2. **动画结束回落属性值**（停止填充语义）：终值已写定，避免双账本。**登场基线注意**：动画自 0 登场时基线必须落在终值而非起点，否则播完回落 0 整体隐形（贴边把手登场淡入曾踩此回归）。
3. **新动画替换在途动画**（快照替换语义）：不叠加、不排队。
4. **隐藏回调防陈旧**：显隐管理为每次隐藏记代数（generation），完成回调校验代数与当前状态，陈旧回调不执行。

**入场事件区分与交错**：只有**真正的新增项**才播入场动画；重排、图标回填、改名、撤销恢复一律不播（「表面展开的交错重播」与「新增项落位」是两件事）。交错步长 40ms 带封顶 `min(i, 8)`——第 9 项起同帧出现，长列表尾部不罚等待；位移幅度分族：卡片 6px、瓦片 8px（同机制不同量级）。

**悬停意图事务**（hover 触发激活级动作时）：布防 timer → 到期**重验指针仍在目标内**才提交，离开即取消；迟到旧离开不取消已被取代的新意图。防扫边误触由事务重验达成，**不另设防抖层**。结构性前提：悬停只做纯视觉预览，激活属点击——hover 直接触发激活级内容切换是反模式。

## 四、交互状态类型学

新控件先在类型学矩阵找归属（复用整行范式），无归属才提新类型并登记。矩阵摘要（Hover｜Pressed｜Disabled）：

| 控件类型 | Hover | Pressed | Disabled |
|---|---|---|---|
| 头部图标钮（含危险钮） | 层淡入（悬停面＋悬停边） | 层切活动层色 83ms | 0.4 |
| 通用文字钮/折叠开关钮 | 瞬切换底＋换边 | 瞬切活动层色 | 0.4 |
| 卡片操作钮网格 | 层淡入＋图标转强调色 | 层切活动层色 | 不禁用（矩阵隐藏＋守卫） |
| 勾选钮 | 环换强调色 167ms | —（即时选中反馈） | 无 |
| chip 过滤轨钮 | 瞬切换底＋换边 | 瞬切活动层色 | 0.4 |
| 设置开关（自绘） | 仅描边 | — | 0.4 |
| 导航项/分段控件 | 瞬切悬停面 | — | 无 |
| 下拉框（本体/列表项） | 本体仅换边；列表项换底 | — | 代码级禁用 |
| 菜单项 | 换悬停面 | 顶层换活动层色 | 0.4 |
| 快捷操作瓦片 | −2px 位移 167ms | 0.96 缩放 83ms | 无 |
| 贴边把手（窗口级命中面） | 提亮＋强调指示 167ms；60ms 意图事务 | —（命中面非钮） | 无 |
| 容器变换弹层缩略钮 | 仅换边 | 透明度 0.85（孤例） | 无 |
| 文本输入框 | — | — | 0.4＋强调色聚焦描边 |
| 滚动条滑块 | 加宽 4→6＋换色 167ms（双层交叉淡入） | — | — |
| 设置卡（整卡） | — | — | 0.6（整卡灰化档） |

（0.4/0.6＝motion.opacity.control-disabled/card-disabled；命中区规格按类型登记不 token 化：图标钮 30×30、文字钮 30、下拉 32、导航项 34、分段 26。）

**hover 双轨三支系**（悬停反馈的承载机制只有两种，瞬切轨内按「改什么」分三支）：

| 支系 | 对象 | 表现 |
|---|---|---|
| ①层淡入（动画轨） | 复合图标元素（头部钮/操作钮/导航标签/chip） | 独立悬停层交叉淡入 167ms |
| ②属性瞬切 | 单表面轻控件（文字钮/chip/导航/分段/菜单项/瓦片名带） | 触发器直换背景/描边，零时长 |
| ③仅描边 | 密集内容控件（下拉框/弹层缩略钮/设置开关） | 只换悬停描边色，不换底不位移 |

**pressed 三范式**：换色（标准钮族，活动层色 83ms）／缩放 0.96（瓦片族）／透明度 0.85（白底码面孤例）。**无按压态类**：轻量选择类（勾选/导航/分段/开关/下拉/chip）——选中/弹层本身即反馈；判别原则：按压态只加给「按下即执行」族，「按下即选择」族用选中态表达。

**禁用两档与不可用≠禁用**：控件族 0.4/整卡灰化 0.6；叠加（钮 0.4 叠卡 0.6 内）合成 ≈0.24 已裁定可接受，不引入第三档；发现散档即归一。**不可用性不用禁用态表达**——禁用元素不可命中、点击穿透成误触；正解＝入口守卫（点击校验并反馈）＋视觉徽章/灰态，元素保持可命中；矩阵隐藏优先、置灰为辅。

**Focus 矩阵**：非文本控件不参与 Tab 焦点＋无焦点视觉；可见键盘焦点仅文本输入框（强调色描边）与多选勾选钮（三态或显隐）两处。判别原则：焦点视觉只加给「键盘操作真实到达」的元素。

**分层叠加（状态视觉的图层结构）**：填充层/环层/命中层各司其职，状态切换＝目标层不透明度交叉淡入，基线层几何与内容零变化；操作格固定预留（状态变化不引起重排）；悬停上浮用渲染位移不参与布局。

## 五、例外通道（窗口级连续迁移）

**恒定几何是默认铁律**：窗口状态迁移**一次矩形变更到位**（单次系统放置调用＋消息守卫拦截中间矩形），观察到的每个矩形 ∈ {初始, 终态}；禁止区域裁剪伪装、禁止动效/延迟/隐藏窗口装饰性掩盖中间态。

**唯一例外通道**＝经唯一放置动画服务的连续受控迁移，五条边界：①**单一矩形权威**（动画期间几何权威归动画服务；任何外部放置入口先取消〔一次放置调用到达终态〕再应用）；②**逐帧单调**（缓动单调⇒物理域取整后非严格单调）；③**终态唯一**（首帧立即应用、末帧精确落位、完成回调恰一次）；④**可中断可重定向**（重定向捕获当前实时进度为新起点、时长按剩余距离比例重映射封顶满时长，**禁原点重放**——收缩途中指针追入即从当前进度反转）；⑤**减动效直达**（例外通道不豁免减动效）。例外必须契约化登记；锁定测试断言单一权威/单调/终态唯一；可注入时钟（生产＝渲染帧时钟，测试＝手动推帧）让动画可逐帧断言。范式细节见 [features-worked-examples.md](features-worked-examples.md) 例二。

## 六、减动效（统一退化口径）

- **触发同一开关**：系统「减弱动效」与用户设置关闭**同键**（桌面端用户覆盖写进系统动画键资源、恢复即移除；Web 端 `prefers-reduced-motion` 统一承载）。全部动效消费同一开关，不允许只关一半。
- **退化规则**：运动型动效取消（保留状态终值）→ 快档纯淡出或立即定格；缓动退化为 linear；**时序性延迟保留**（排队收起等是时序编排非动效）；窗口级动画全链直达终态。
- 动效永不作信息唯一载体：关动效后一切状态变化仍可感知（失败态闪烁必须转向常显态）。

## 七、非线性动画两级先例（大位移/形变不走纯淡入）

| 级别 | 先例 | 要点 |
|---|---|---|
| 容器级 | 容器变换弹层（缩略图↔放大层） | 动画对象＝外层整卡（四变换同帧启动使矩形插值成为结构性质）；文字后段浮现（≈60% 进度）；缩略图防双影淡出；收回＝对齐落位回显（交接段两元素等斜率线性交叉、合成存在感恒≈1）；独立时长组＋专用曲线 |
| 窗口级 | 贴边 peek 收缩/展开 | 整窗同尺寸纯平移，经唯一放置动画服务（§五）；时长/缓动全部复用既有 token（收缩 167 加速、展开 250 减速） |

通用要点：非线性动画必须有**单一权威仲裁**；可注入时钟让动画可逐帧断言。完整配方见 [features-worked-examples.md](features-worked-examples.md) 例二/例三。

## 八、动效六原则（评审基准）

1. 进入减速、出场加速，退出比进入快；登记例外按场景标注，不泛化不加档。
2. 动效可中断、可重定向：新动画必须先复位终值；不得让用户等动画播完。
3. 动效不阻断命中测试；永不作传达信息的唯一方式。
4. 减弱动效统一退化口径（纯淡出或定格）；时序性延迟保留。
5. 状态迁移的视觉交接防闪烁机制不被动画破坏。
6. 图标取自开源图标库几何重绘，不随应用分发字体文件。

## 九、验收自查

- ☐ 时长只有三档＋登记例外＋契约化独立组；场景锚定不加档；行为计时器豁免成文。
- ☐ 双缓动按**语义**各就各位；位移动画无数值判据；缓动单点实例消费。
- ☐ 动画全部可中断（复位终值＋停止填充＋快照替换＋防陈旧回调）；登场基线落终值。
- ☐ 交错有封顶；入场动画只在真正新增时播；悬停触发激活级动作走意图事务。
- ☐ 交互状态按类型学落位（无第四种 hover/pressed）；禁用两档；不可用走入口守卫；Focus 矩阵最小化。
- ☐ 窗口迁移一次变更到位或走五条款例外通道；减动效统一退化、时序保留。
- ☐ 大位移/形变走两级先例之一，有单一权威仲裁与可注入时钟。
