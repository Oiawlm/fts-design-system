## 一、数值与来源治理

**A1 壳圆角幽灵 token**｜主违 §一
现象：窗壳圆角出现第二个 token，与系统窗口层裁剪值并存且可能不同值。根因：壳圆角权威是系统级裁剪，界面内第二份声明只会漂移——两值分叉即壳与内容自裁剪错位。正解：删幽灵 token，唯一权威一枚常量＋锁定测试镜像；凡权威在系统层的值，界面侧不立第二来源。

**A15 代码构建的 UI 快照画刷**｜主违 §一
现象：界面开着切深色主题，代码构建的行不跟随、停在旧主题色。根因：构建瞬间「查找资源」把画刷实例快照持有，字典整本换装后旧引用不更新——第二数值源的时间维变体。正解：一律活解析引用（动态资源语义），主题活切换即跟随；双主题切换探针入锁定测试。

**A16 场景时长新增档位**｜主违 §三
现象：每个新功能引入自己的毫秒数，时长档位表持续膨胀。根因：没把「时长＝档位资源」当约束，场景值被当自由变量。正解：场景常量锚定既有三档（或登记为场景原始值），永不加档；独立时长组是契约化例外不是后门。

**A21 缓动曲线硬编码散布**｜主违 §一＋§四
现象：曲线实例散布多处动画代码，同义曲线多份实例；锁定测试只能断言实现类型，收编即碎。根因：缓动没有单点工厂，每处动画自备曲线。正解：缓动单点实例，全部动效（含窗口放置/入场/反馈层/上浮）经它消费；锁定测试断言「同一实例」。

**A23 禁用不透明度散档**｜主违 §三
现象：禁用灰度多档并存（0.35/0.45/0.5 同现），各自字面量，无档位语义。根因：逐控件随手写透明度；且禁用态还被错当交互守卫用（见 A 表 §六关联）。正解：归一两档（控件 0.4/整卡 0.6），消费者一律引用＋锁定测试互锁；禁用表达＝入口守卫优先、置灰为辅。

**A24 文案双写**｜主违 §一（同构）
现象：同一组固定文案（标题/占位提示/空态说明）在两个构造点逐字重复。根因：文案被当成局部字符串而非设计数值——与幽灵 token 同构，改一处漏一处。正解：收敛唯一来源类（常量/资源单点），调用方不得写第二份。

## 二、布局与几何稳定性

**A2 「公式限宽＋面板再量化」双口径**｜主违 §二
现象：网格列数按公式算固定宽，再交布局面板量化——实际恒少一列＋行内死区。根因：两个几何口径失配（公式节距与面板节距差一个沟道）。正解：拉伸填充单一几何源——列数与元素宽唯一计算来源一个纯函数，容器自排版，行满排＝视口。

**A3 滚动条独立布局列**｜主违 §二
现象：内容多时滚动条出现、条目变窄；变少后消失、变宽——位置漂移。根因：默认模板把滚动条放独立布局列（宽 0↔N 切换），且系统滚动条样式带最小宽度下限（实测约 17 DIP）压过自定义瘦条。正解：overlay 滚动条（定制模板＋条带最小宽高归零）。

**A4 稳定留槽（常驻占位）**｜主违 §二
现象：为防 A3 漂移让滚动条永远占位。根因：用错误机制（占位）修补错误机制（占宽）。正解：overlay 单一机制根治，不留槽。

**A5 宽度补偿/负边距特判**｜主违 §二
现象：用负边距或宽度加算逐表面抵消滚动条占位。根因：补丁式特判随每个新表面复制——修漂移的代码成了漂移源。正解：overlay 机制一次根治；补偿类特判禁用。

**A7 内容列居中对齐**｜主违 §二
现象：多页窗口各页内容列宽随当页最宽内容收窄，页页不等宽（实测两页相差逾百 DIP）。根因：居中对齐让容器宽收缩到内容宽，而非内容在统一宽内居中。正解：拉伸填充＋最大宽上限（受钳的拉伸自动居中），多页等宽。

**A8 内缩量动态派生**｜主违 §二
现象：正文内缩随悬停状态计算，文字抖动回流。根因：瞬态状态参与静态几何计算。正解：内缩是静态值，任何时刻零像素争用。

**A9 悬浮覆盖层替代静态内缩**｜主违 §二
现象：操作按钮悬停时浮在正文上方。根因：按钮与正文争用同一像素——正是文字避让要消灭的争用。正解：静态排他预留（内缩常驻）＋固定操作格。

**A10 等分面板/定宽换行面板做按钮区**｜主违 §二
现象：等分面板里隐藏一个按钮后其余补位重排；换行面板换行语义随宽度漂移。根因：两者都以「可见子项」排布，不支持「隐藏留空」。正解：显式固定行列。例外判据：等分且恒列数本身就是需求时（chip 轨），等分面板恰是正解。

**A12 条件性外形（越屏裁切）**｜主违 §二
现象：窗口向屏外平移一个圆角半径换取收起态边缘平直。根因：条件性机制使外形随停靠侧/显示器布局漂移。正解：删机制——可见态四角圆角恒定、窗口恒在工作区内。

**A14 纯透明度隐藏**｜主违 §二
现象：按钮「隐藏」后仍占位或仍可命中，网格其余按钮位置微动。根因：透明度为零既不改布局也不退场命中。正解：布局塌缩＋统一显隐管理（激活立即显示、失活动画完成后塌缩、动效关闭立即切、防陈旧回调）；固定网格下塌缩天然留空格。

## 三、渲染与视觉保真

**A6 弹窗假圆角三件套**｜主违 §一（壳权威）
现象：弹窗透明背景＋margin 挤出圆角＋手工投影；与整体界面不搭。根因：透明壳透下层内容色、假圆角边缘锯齿、手工阴影与系统阴影叠加——三处都在跟系统窗口层抢「壳的权威」。正解：不透明表面单壳，圆角/阴影唯一来源系统窗口层；失败时直角回退，禁假圆角。

**A11 特效进文字子树**｜主违 §五
现象：卡片正文发糊（亚像素抗锯齿失效）；长列表滚动掉帧。根因：带特效的元素把整个子树渲染进中间位图并强制关闭亚像素文字渲染；逐卡片实例化还拖垮虚拟化。正解：阴影/特效隔离到不含文字的独立层（三层结构），共享冻结单实例。

**A13 分层透明壳**｜主违 §一（壳权威）
现象：用分层透明窗口实现圆角与阴影。根因：分层窗口整窗离屏合成性能差，且用不了系统材质与硬件圆角。正解：系统窗帧（整窗玻璃帧）＋系统材质壳＋系统圆角；材质不可用回退不透明表面。

## 四、交互与动效语义

**A17 模式化交互（编辑模式开关）**｜主违 §六
现象：全应用唯一「编辑模式」开关——进出状态易漏，显隐机制还吞点击（合成可达、实机不可达）。根因：模式切换是平行的第二套交互语义，与常态手势冲突。正解：常态分区手势＋多选＋右键菜单，删除模式开关。

**A18 拖拽追赶动画＋保存往返门住**｜主违 §六
现象：拖动条目粘滞感强；松手先闪旧序帧再落新序。根因：跟随用动画追赶（永远追不上指针）＋落位被「持久化往返」门住后全量重建。正解：跟随直接赋值＋命中槽缓存＋乐观上屏（同一 UI 消息内生效）＋持久化旁路化＋失败回滚。

**A19 交互上限由布局属性声明**｜主违 §六（真实可达）
现象：窗口可交互缩到极小、拉到远超上限。根因：布局属性上下限只约束布局引擎，不约束系统消息路径——「合成可达、实机不可达」的镜像。正解：在系统尺寸协商消息处强制一切尺寸变更；与系统交互的封送结构必须严格同构（错一字节＝约束从未生效）。

**A20 覆盖层就地编辑/幽灵入口**｜主违 §二（结构对齐）
现象：编辑框盖写在错误行（旧文本与编辑框两段并存）；幽灵入口与正文同格叠加。根因：编辑器不在被编辑内容的结构位置——z 序盖写代替结构对齐。正解：编辑器落原位（同格结构对齐、不透明盖写）、入口并入固定网格；硬编码偏移对齐一律否决。

**A22 位移动画按数值方向选曲线**｜主违 §四
现象：悬停抬升（向负值位移）被配上加速曲线——抬升加速、回落减速，与「进入态减速」宣称相反；文档-实现不一致长期潜伏。根因：「目标<起点＝出场」是透明度语义判据；位移可正可负，负向进入在数值上像出场。正解：按目标态语义选曲线（进入→减速/离开→加速）；透明度场景数值判据恰同向可用，位移动画禁用；语义判据写进规范并配锁定测试。
